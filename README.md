# LLM Wiki｜页面级设计最终入口

技术架构保持 **.NET 10 + C# + WPF + WPF-UI 4.3.0 + MVVM**，全WPF，不引入WebView2或第二套UI框架。

产品定位是**由外部 Agent 持续维护 Wiki 的本地知识编译系统**：用户管理 Raw Sources、设定 purpose/schema、审核知识变更；Agent 负责 Ingest、Query、Lint 的阅读与写作建议，应用负责暂存、差异、审核、受控提交和版本恢复。
