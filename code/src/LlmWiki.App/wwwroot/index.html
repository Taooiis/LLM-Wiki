小白指南

分类速查，完整版见使用说明.md。

一、快速上手三步

1. 运行程序，面板会自动打开在浏览器中。用完直接关闭即可。

2. 新建知识库 → 源文档页上传 .md / .docx / .xlsx → 配置页填写目标和规则。

3. 工作流页先做接入（边界说明进 Agent 配置）→ 再生成 Ingest 等提示词 → 粘贴执行 → 回面板刷新看 wiki/ 成果。

二、日常使用：文档与编辑

源文档页：＋新建文档 / 上传 / 点编辑弹窗修改 / 删除。只收 .md/.txt。

改了哪些不用记：顶部待处理变更自动列出，勾选 → 生成选中 Ingest → 执行完标记已处理。

路径浏览页：刷新目录树，点文件名弹窗编辑，下方同步预览。

弹窗通用操作：改后标题栏 ● 未保存提醒；Ctrl+S 保存；Esc 关闭（未保存会确认）；底部 toast 提示结果。

重要规则：源文档的新增/修改/删除只写文件并自动记入 wiki/log.md，wiki 页面不会自己变：保存后按 toast 提醒去工作流页重新 Ingest 该文档。

三、管理与配置

存储路径：左栏“新建 / 存储路径”里点浏览…会弹出系统文件夹选择器（可直接进盘符、网络共享），或手填路径，点更改路径立即生效；旧文件不会自动搬移，需手动复制。

配置页：点 purpose.md / schema.md 旁编辑，弹窗改目标规则，保存即生效。

目录：库名/ 下 purpose.md、schema.md、raw/sources/、wiki/（index/log/overview/entities/concepts/…）。

四、AI 协作：工作流与边界说明

第一步先接入：点“生成边界说明”→ 复制 → 粘贴进 Agent 配置（全局 AGENTS.md 等），新会话可直接读库；换库或大改后重新生成覆盖。

工作流页：Ingest（填源文件名，支持批量留空全选）/ Query（填问题）/ Lint / Compare / 变更文档 Ingest（只处理新增/改动/删除） → 生成 → 一键复制 → 粘贴到已接入的 AI 工具执行 → 回来刷新。

不开面板可用 prompts/ 下离线模板（ingest/query/lint/compare/context）。

五、运行与网络

改完代码行为没变：先重启程序确保生效。

局域网：同一 WiFi 下用局域网地址访问；防火墙弹窗点允许。

多电脑（库在 A，B 要用）：B 直接用浏览器打开 A 的面板可看可改；B 想自己跑 AI，A 把 wikis 文件夹共享，B 面板点浏览… → 局域网一路点选共享，路径自动填入。双方别同时改同一文件。
