## 2. 用户体验问题清单（触发场景）

1. 编辑弹窗遮挡列表与目录树，长文编辑窗口过小（每次编辑源文档）。
2. 保存失败仍关弹窗 → 用户以为已保存（写盘失败场景）。
3. MessageBox 风格与整体 UI 不一致（Esc 关闭时）。
4. 源文档页与目录浏览页两套编辑体验，行为不一致（已实测）。
5. 未选中文件时工具栏仍显示"删除"等按钮（禁用态按钮排）。
6. 新建知识库用固定输入框占位（指南要求内联输入行、Enter/Esc 提交/取消）。
7. 自制文件夹选择器维护成本高、与系统行为不一致。
8. 紫色 accent 残留（上一轮实验性引入，指南明确禁止）→ 阶段 1 清除。
9. 工作流卡片全部平铺长提示词，页面冗长（指南 8.1 要求折叠预览）。
10. 分享开关状态、路径验证状态等长期状态依赖 toast，缺常驻显示。

## 5. 风险与兼容性

1. **未保存保护覆盖面**：切页面导航目前经 INavigationService，拦截点需要挂 MainWindow 层；遗漏路径会静默丢稿 → 阶段 2 先做工作区内保护（切文件/切库），跨页/关窗保护放阶段 5 统一补。
2. **原生 FolderPicker 与 UNC 需求**：OpenFolderDialog 支持 UNC 输入但无"局域网机器浏览"；多电脑协作场景（spec §5.3）有回退路径（手输 UNC）。已按指南 11.6 接受。
3. **AvalonEdit 引入**：指南 14 建议 AvalonEdit 做行号/等宽编辑器，但"不引入新包"约束与它冲突 → 第一版用 WPF TextBox（等宽、无行号）实现 Editing 态，AvalonEdit 留待你确认后再引入。
4. **Markdown 预览**：项目已有 Markdig；Preview 态第一版仍显示纯文本预览，渲染预览（WebView2/FlowDocument）列为后续可选，不在本轮承诺。
5. 现有"上传转 md"行为**保持不变**（指南 5.4：多文件类型策略待产品确认，不擅自改）。
