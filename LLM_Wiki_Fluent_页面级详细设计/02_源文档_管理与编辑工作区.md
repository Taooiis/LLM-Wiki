# 02｜源文档：管理与编辑工作区

## 1. 页面目标

源文档是资料进入知识库的入口。核心任务包括查看文件、上传、新建 Markdown、编辑文本文件、删除文件、查看待处理变更。页面必须保持“左侧文件列表 + 右侧文档工作区”，预览和编辑在右侧同一位置切换，不再使用传统编辑弹窗。

## 2. 整体布局

┌──────────────────────────────────────────────────────────────────────────┐
│ 源文档                                                [新建文档] [上传文件] │

├──────────────────────────────┬───────────────────────────────────────────┤
│ 当前知识库：产品知识库         │ 产品需求说明.md                  [编辑] […] │

## 3. 左侧文件列表

### 3.1 列表头

- 当前知识库名称必须持续可见。
- 搜索框只过滤当前已加载列表，按现有规格不额外触发磁盘读取。
- 类型筛选可选：全部、Markdown、文本、PDF、Office、其他支持类型。筛选项只能覆盖已实现白名单。
- 列表标题显示文件数量。

### 3.2 文件行

每行包含：
- 类型图标：MD/TXT/PDF/XLSX/DOCX/HTML/JSON 等。
- 文件名，最多两行或单行省略。
- 辅助信息：文件大小、修改时间。
- 只读类型显示“只读”徽标。
- 当前选中项用低饱和蓝色背景 + 左侧 2px 蓝线。

交互：
- 单击：加载右侧预览。
- 双击：可编辑文本文件进入编辑；只读文件按策略打开或仍留在预览。
- 右键菜单：编辑（可编辑时）、打开（只读时）、复制相对路径、删除。
- 删除前确认，删除后清空右侧工作区并刷新待处理变更。

### 3.3 待处理变更

列表底部或独立折叠区显示待处理变更数量。点击后展开变更列表，显示动作、新增/修改/删除、文件名、时间和勾选框。

- 勾选状态不能因列表虚拟化/滚动而丢失。
- “生成选中 Ingest”只有选中项大于 0 时可用。
- 点击后跳转工作流页，自动填入文件名并生成对应提示词。
- “标记已处理”仅对明确选中的变更生效；不得无提示清空未勾选项。

## 4. 右侧文档工作区

### 4.1 Empty 状态

没有选中文档时显示居中图标、标题“选择一个源文档”、说明“从左侧列表选择文件，或上传/新建一份资料”，以及两个快捷操作“上传文件”“新建文档”。

### 4.2 Preview 状态

顶部工具栏：
- 文件名（主标题）。
- 完整相对路径（辅助文本，等宽字体）。
- 右侧操作：可编辑文件显示“编辑”；只读文件显示“打开”；更多菜单含复制路径、删除。

正文区域：
- Markdown 使用排版预览；TXT/代码/JSON 使用等宽文本预览；PDF/Office 等按当前已确认策略展示预览或只读信息。
- 预览内容区可滚动，不影响左侧列表。
- 顶部或底部显示文件类型、大小、修改时间、保存状态。

### 4.3 Editing 状态

编辑状态必须在原右侧区域内完成，不弹出独立小窗。

```text
┌────────────────────────────────────────────────────────────────┐
│ 编辑：产品需求说明.md                 ● 有未保存更改 [保存] [取消] │
│ raw/sources/产品需求说明.md                                     │
├────────────────────────────────────────────────────────────────┤
│ [Markdown] [预览] [分屏]                         字数 1280       │
│                                                                │
│ # 产品需求说明                                                  │
│                                                                │
│ 在这里编辑文档正文……                                            │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│ Ctrl+S 保存    Markdown 文件    行 18，列 1                      │
└────────────────────────────────────────────────────────────────┘
```

- 编辑器填满右侧工作区；不能在卡片里再嵌套一个小型编辑框。
- 顶部显示文件名、路径、保存状态、保存/取消操作。
- 支持编辑/预览/分屏模式（如果现有编辑器能力允许）；最小实现可先实现编辑与预览切换。
- Ctrl+S 保存；Esc 不直接丢弃内容，触发退出编辑保护。
- 保存成功：状态变为“已保存”，更新修改时间，自动登记待处理变更并追加 `wiki/log.md`（沿用现有业务逻辑）。
- 保存失败：编辑内容保留，状态变为“保存失败”，错误详情显示在工作区内，提供“重试保存”。不能关闭编辑器。

## 5. 新建文档

- 点击页头“新建文档”后，右侧直接进入 Editing / New 状态。
- 文件名输入位于工具栏下方或工具栏左侧，默认建议 `.md`，但不要在用户未确认时自动覆盖已有同名文件。
- 文件名为空、非法字符、路径穿越、同名冲突时，在输入区附近显示错误。
- 内容编辑区立即可用。
- 点击“创建”或 Ctrl+S：校验文件名→写入 `raw/sources/`→刷新列表→选中新文件→显示成功反馈。
- 创建成功后提示用户后续可去工作流页重新 Ingest。
- 创建失败不得清空编辑内容。

## 6. 上传文件

- 点击“上传文件”调用系统文件选择器，支持多选。
- 选择完成后进入上传处理状态，展示文件名、进度、成功/失败结果；若无法获取精确进度，显示阶段状态，不要编造百分比。
- 同名冲突必须明确选择覆盖/跳过/取消（具体策略需与现有实现对齐）。
- 上传完成刷新列表；新文件按业务规则生成待处理变更。
- **重要：** 原规格中 `.docx/.xlsx` 转 Markdown、原件存 `raw/original` 与“原样存储”的方案存在待确认冲突。此页面只实现已确认策略，不得自行改写文件转换行为。

## 7. 删除与未保存保护

删除源文件：确认对话框明确文件名、相对路径和“删除后会记录一条待处理变更”。删除后刷新列表、清空预览、更新首页计数。

未保存保护统一提供：
- `保存后离开`：保存成功后执行原导航/切换动作。
- `放弃更改`：丢弃本次编辑并执行原动作。
- `继续编辑`：关闭确认并保留当前内容。

不允许“点关闭就直接丢失”。

## 8. ViewModel 建议

`SourceDocumentsViewModel`：当前库、文件集合、搜索词、类型筛选、选中文件、变更集合、选中变更集合、加载状态、上传状态。

`DocumentWorkspaceViewModel`：模式（Empty/Preview/Editing/ReadOnly）、当前文档、编辑内容、原始内容、保存状态（None/Saved/Dirty/Saving/Failed）、文件名、相对路径、错误信息、字数/行列信息。

命令：`LoadDocuments`、`SelectDocument`、`CreateDocument`、`UploadDocuments`、`EnterEditMode`、`SaveDocument`、`CancelEdit`、`DeleteDocument`、`GenerateSelectedIngest`、`MarkChangesProcessed`。

## 9. 验收清单

- [ ] 选中文档后右侧能正确加载真实内容，不出现空白假预览。
- [ ] 预览→编辑在同一工作区切换，不打开模态编辑窗。
- [ ] 新建文档也复用同一编辑工作区。
- [ ] Ctrl+S 可保存；保存成功后自动登记变更并写日志。
- [ ] 保存失败保留内容，显示原因并支持重试。
- [ ] 切换文件、切换库、切换页面、关闭窗口均触发未保存保护。
- [ ] 上传多文件时能显示处理结果；失败文件不会被误报成功。
- [ ] 删除后列表、预览、变更计数正确刷新。
- [ ] 文件类型处理严格遵循最终确认的白名单和转换规则。
