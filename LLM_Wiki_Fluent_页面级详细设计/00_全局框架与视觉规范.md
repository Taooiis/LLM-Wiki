# 00｜全局框架与视觉规范

## 1. 目标效果

整体接近概念图中的 Windows 11 桌面应用：左侧深色导航、顶部轻量标题/搜索区、右侧宽阔工作区、卡片有轻微层次而非强烈投影。界面应稳重、清晰、紧凑，不要做成紫色科技风，也不要做成网页后台的密集表格风。

## 2. 主窗口结构

建议采用三段式：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ LLM Wiki   [搜索知识库、文档或功能 Ctrl+K]                [帮助] [窗口控制] │
├──────────────────────┬─────────────────────────────────────────────────────┤
│ 品牌/应用名           │ 页面标题                           页面主操作        │
│                      ├─────────────────────────────────────────────────────┤
│  ◉ 首页               │                                                     │
│  ▤ 源文档             │                                                     │
│  ▥ 目录浏览           │                    页面内容区                       │
│  ◫ 工作流       3     │                                                     │
│  ⇧ 分享               │                                                     │
│                      │                                                     │
│                      │                                                     │
│                      │                                                     │
│  ──────────────────  │                                                     │
│  ◇ 小白指南           │                                                     │
│  ⚙ 配置               │                                                     │
│  ⚙ 设置               │                                                     │
├──────────────────────┴─────────────────────────────────────────────────────┤

└────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 尺寸与自适应

- 默认启动尺寸建议 1440×900，最小尺寸建议 1180×760。
- 左导航宽度 224px；可折叠到 64px 图标栏。折叠状态持久化。
- 顶部标题/搜索区高度约 52px；页面标题区 72–88px；底部状态栏 28px。
- 内容区左右 Padding 24px，上下 20px；卡片间距 16px。
- 页面内容区允许独立滚动，导航栏和顶部区域不随内容滚动。
- 小窗口时优先压缩卡片列数：4列→2列→1列；不要让按钮、文字互相覆盖。

## 3. 导航规范

导航项固定为：首页、源文档、目录浏览、工作流、分享；底部为小白指南、配置、设置。

- 当前项：使用低饱和蓝色半透明底（例如 `#163A55`），左侧可有 2px 蓝色指示条；不使用渐变胶囊。
- 图标：使用 WPF-UI / SymbolIcon 对应 Fluent 图标，统一 16–18px。
- 工作流待处理数量仅在大于 0 时显示小徽标；颜色用警示橙/红，不要让整个导航项变红。
- 导航切换保留页面自己的搜索、筛选、滚动位置；切换知识库时刷新依赖当前库的数据。
- 编辑器有未保存内容时，导航切换必须先走统一未保存保护流程。

## 4. 顶部搜索

- 顶部搜索框宽度建议 360–460px，placeholder：`搜索知识库、源文档或 Wiki 内容…`。
- `Ctrl+K` 聚焦，Esc 收起建议列表，Enter 打开第一条结果。
- 结果按知识库 / 源文档 / Wiki 文档 / 功能入口分组。
- 搜索无结果时展示清晰空状态和清空入口。
- 如果当前搜索能力仅支持本地文件名，文案不得暗示支持全文搜索。

| ControlBackground | `#1F1F1F` | 输入控件 |
| Divider | `#3A3A3A` | 分割线 |

### 5.1 字体与间距

- 页面标题 26–28px / Semibold。
- 区块标题 17–18px / Semibold。
- 卡片标题 14–16px / Semibold。
- 正文 13–14px；辅助信息 11–12px。
- 默认圆角：卡片 10px；输入框 6px；按钮 6px；对话框 10px。
- 内容边距 20–24px；卡片间距 14–16px；列表行高 44–52px。

## 6. 控件与组件约束

- 主窗体：WPF-UI `FluentWindow`。
- 导航：`NavigationView` / 对应导航控件。
- 图标：`SymbolIcon`，统一图标尺寸。
- 通知：WPF-UI `Snackbar`。
- 聚焦确认：WPF-UI `ContentDialog` 或项目已封装的统一 Dialog。
- 开关：`ToggleSwitch`。
- 搜索：`AutoSuggestBox` 或现有搜索控件。
- 卡片：优先 `Border + Grid` 或 WPF-UI 卡片控件，不要额外引入完整 UI 框架。
- 左右分栏：`Grid` + `GridSplitter`。
- 文档编辑：现有 Markdown 编辑方案；若使用 AvalonEdit，需统一暗色配色。
- Markdown 预览：沿用现有渲染方案；若使用 WebView2，必须限制本地资源访问和脚本权限。

## 7. 状态与交互统一

每个页面都必须定义：初始/加载/空/正常/错误/禁用/执行中状态。

- Snackbar：只提示一次性结果，不承担持久状态。
- 页面内状态：显示保存状态、服务状态、任务进度等长期信息。
- 异步请求：避免 UI 线程阻塞；重复点击期间禁用同一操作。
- 错误信息：尽量说明原因和下一步，不只显示“操作失败”。
- 不允许使用系统 `MessageBox` 作为主要交互。

## 8. MVVM / 代码组织建议

```text
Views/
  Shell/MainWindow.xaml
  Pages/HomePage.xaml
  Pages/SourceDocumentsPage.xaml
  Pages/DirectoryBrowserPage.xaml
  Pages/WorkflowPage.xaml
  Pages/SharePage.xaml
  Pages/ConfigurationPage.xaml
  Pages/SettingsPage.xaml
  Pages/GuidePage.xaml
  Controls/DocumentWorkspace.xaml
  Controls/DocumentToolbar.xaml
  Controls/DocumentStatusBar.xaml
  Dialogs/ConfirmDialog.xaml
  Dialogs/UnsavedChangesDialog.xaml
ViewModels/
  ShellViewModel.cs
  Pages/*ViewModel.cs
  Controls/DocumentWorkspaceViewModel.cs
  Dialogs/*ViewModel.cs
Resources/
  Colors.xaml
  Typography.xaml
  Controls.xaml
  Icons.xaml
```

以上是建议，不要求为迁就目录结构而大规模搬迁现有代码。命令和状态应由 ViewModel 管理，View 不直接操作文件系统。

## 9. 全局验收

- [ ] 深色主题下所有页面均无紫色主色或紫色渐变。
- [ ] 导航栏宽度、页面边距、卡片间距统一。
- [ ] 1100×650 下核心操作不被裁切。
- [ ] 折叠导航后图标提示和当前页状态仍清楚。
- [ ] 页面切换不会静默丢失未保存内容。
- [ ] 加载、空、错误、禁用状态均有明确 UI。
- [ ] 所有图标语义准确，按钮有 Tooltip 或文字说明。
