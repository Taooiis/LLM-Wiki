# 06｜配置、设置与小白指南

## 1. 页面关系

底部导航包含三个入口：配置、设置、小白指南。三者职责分开：
- 配置：知识库运行所需的路径、purpose、schema 等业务配置。
- 设置：应用自身偏好，如主题、版本信息、更新检查。
- 小白指南：静态帮助内容，指导新用户完成日常任务。

## 3. 存储路径配置

- 路径输入框支持手动输入，输入变化立即触发格式/可访问性校验。
- 浏览按钮调用 Windows 原生 Folder Picker；不要自制一个复杂文件夹浏览弹窗，除非现有业务确实依赖 UNC 等特殊能力且系统选择器无法满足。
- 显示路径状态：未验证、有效、目录不存在（可创建）、无权限、路径格式错误、网络路径不可达。
- 保存按钮仅在路径有效或允许创建时启用。
- 保存成功：写入配置文件、创建必要目录、更新全局路径服务、刷新知识库列表和相关页面。
- 路径切换期间需要明确处理正在编辑的文档、运行中的分享服务和工作流任务；不得静默切换导致数据写入旧路径或丢稿。
- 恢复默认路径需明确显示目标目录；若涉及迁移数据与否，必须遵循现有业务规则，不得默认搬迁或删除旧目录。

## 4. purpose.md / schema.md 编辑

- 两张卡片分别展示文件用途、当前状态（存在/缺失/未保存）。
- 点击编辑后进入统一 DocumentWorkspace 或统一内联编辑区域，不再弹出独立小窗。
- 保存时写回对应文件，并记录现有日志规则。
- 两个入口（配置页与目录浏览页）应共用文件读写服务，避免一处保存覆盖另一处未保存内容。
- 文件缺失时提供“创建默认模板”入口；创建前展示将写入的默认内容摘要。

## 5. 设置页

内容保持简洁：
- 外观：Dark / Light 切换；默认 Dark。主题选择即时生效并记住。
- 版本：应用版本号、构建信息（有真实数据时展示）。
- 更新：检查更新按钮，显示检查中、已是最新版本、新版本可用、检查失败。
- 可选：启动行为、日志目录等设置仅在产品已有对应功能时出现，不凭空增加配置。

主题切换后必须检查所有页面、弹窗、编辑器、Snackbar、TreeView、滚动条都跟随主题，不能只改变主背景。

## 6. 小白指南

使用 5 个分组折叠面板：
1. 快速上手：创建知识库、选择当前库、认识页面布局。
2. 日常使用：上传文档、新建 Markdown、编辑保存、删除文件。
3. 知识维护：待处理变更、批量 Ingest、增量 Ingest、Lint、Compare、Clean。
4. AI 协作：复制提示词、交给 Agent 执行、将结果放回知识库。
5. 运行与网络：存储路径、局域网分享、PIN、安全边界。

指南文字要短句、按步骤、使用与界面一致的按钮名称。截图可后续补充，但不要用与当前实际 UI 不一致的旧截图。

## 7. ViewModel 建议

配置页：`StoragePath`、`PathValidationState`、`PathValidationMessage`、`IsSaving`、`PurposeContent`、`SchemaContent`、各自保存状态。
设置页：`ThemeMode`、`AppVersion`、`UpdateState`。
指南页：`GuideSections`、`ExpandedSection`。

## 8. 验收清单

- [ ] 路径输入即时校验，保存的是最新输入值而非旧值。
- [ ] 浏览路径使用系统 Folder Picker 或有明确理由的兼容实现。
- [ ] 保存路径后所有页面读取同一个新路径。
- [ ] 路径切换不会静默丢失编辑内容或破坏运行中的任务。
- [ ] purpose/schema 均可查看、编辑、保存，保存失败保留内容。
- [ ] Dark/Light 主题完整覆盖所有页面和弹层。
- [ ] 指南五个分组内容与实际操作一致。
