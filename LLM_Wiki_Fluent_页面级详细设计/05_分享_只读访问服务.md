# 05｜分享：只读访问服务

## 1. 页面目标

分享页面用于将当前知识库以局域网只读方式提供给其他设备浏览。用户需要一眼看懂服务是否启动、如何访问、PIN 是什么、当前暴露了什么范围，以及如何停止服务。页面不能只放一个开关。

## 3. 服务状态卡

状态至少包含：未启动、启动中、运行中、停止中、启动失败。

- ToggleSwitch 与真实服务状态绑定，不允许 UI 开关改变但服务未启动。
- 启动中禁用重复点击，展示阶段状态。
- 启动成功后显示地址、PIN 和分享范围。
- 启动失败显示错误原因和重试按钮；开关回到关闭状态。
- 停止时先执行真实停止动作；停止成功后清除可用地址显示或标记为不可访问。
- 服务状态需在页面、状态栏保持一致。

## 4. 地址与 PIN

- 地址使用可复制文本块，长地址自动换行或横向滚动；复制按钮始终可见。
- 多网卡环境如果有多个可访问地址，应逐条展示并注明局域网网卡/地址，不要拼成一个不清晰字符串。
- PIN 使用较大等宽字体，避免与地址混淆。
- PIN 重新生成前说明旧 PIN 失效规则；如果重新生成会断开现有访问，需要提示。
- PIN 不应写入普通日志或错误详情。
- “在浏览器中打开”仅在本机地址可用时启用。

## 5. 分享范围与安全提示

固定显示只读能力清单：
- 允许：目录浏览、文档预览、按权限下载（仅在服务确实支持时）。
- 禁止：编辑、上传、删除、配置修改、工作流执行。
- 服务端必须真正限制写接口；不能只在前端隐藏按钮。
- 仅暴露当前选中知识库或产品已定义的范围；切换存储目录后分享服务应按原规格跟随新目录，需确保运行时路径安全更新。
- 不允许把任意本机路径通过 URL 参数暴露给外部请求。

## 6. 空状态和异常

未启动：展示说明、主开关和“启动分享服务”。
启动失败：错误摘要、详细信息折叠区、重试。
没有可分享知识库：说明先创建或选择知识库，启动按钮禁用。

## 7. ViewModel 建议

- `ShareServiceState`、`IsShareEnabled`、`IsStarting`、`IsStopping`、`AccessUrls`、`Pin`、`SelectedKnowledgeBase`、`ShareRootPath`、`LastError`。
- 命令：`StartShareService`、`StopShareService`、`CopyUrl`、`CopyPin`、`RegeneratePin`、`OpenLocalUrl`。
- 状态必须来自服务层回报，不可仅在 ToggleSwitch 的 setter 中直接置为 Running。

## 8. 验收清单

- [ ] 开关和真实服务状态一致。
- [ ] 启动成功后地址和 PIN 正确展示并可复制。
- [ ] 启动失败有原因和重试入口。
- [ ] 停止后旧地址不可继续访问。
- [ ] 局域网访问只能读，写接口在服务端拒绝。
- [ ] PIN 重新生成的影响范围清楚。
- [ ] 存储路径变更后服务按预期更新，不继续暴露旧目录。
