# 02 快速上手

从零到读到第一篇 AI 整理的知识，共 5 步。

## 第 1 步：创建知识库

1. 首次启动会看到引导页，点 **"新建知识库"**（之后也可点标题栏的库切换按钮 → 新建）。
2. 在弹窗中填写：
   - **知识库名称**：只允许中英文、数字、下划线、中划线（如 `产品研究`）；重名时可点"打开已有知识库"。
   - **场景模板**：通用 / 研究 / 读书 / 业务，只影响 `purpose.md`、`schema.md` 的预填文字。
   - **目标说明（可选）**：这个库为谁服务、回答哪些问题、不收什么。
3. 点 **"创建知识库"**，成功后自动进入资料页。

建好的库是一个文件夹（默认在 `我的文档\LLM Wiki\wikis\` 下），内含预填的规则文件和 `wiki/` 知识骨架。详见 [03 知识库与数据存储](03_知识库与数据存储.md)。

## 第 2 步：添加资料

1. 在**资料页**点 **"添加文件"**，多选本地文件（支持文档/表格/演示/PDF/文本/数据/图片，单文件 ≤ 20 MiB）。
2. 若与现有资料同名，会弹出对照窗口：**取消本批 / 跳过同名继续 / 覆盖同名继续**（覆盖前旧版本自动存入回收站）。
3. 导入完成后显示结果摘要卡（已添加/跳过/失败逐条说明）。

也可以用 **"新建资料"** 直接在应用内写 Markdown 或纯文本。资料保持原格式保存，不转 Markdown。详见 [04 资料管理](04_资料管理.md)。

## 第 3 步：发起整理

1. 到**整理页**，默认在"更新知识"页签：
   - **处理范围**：待整理变更 / 所选资料（资料页勾选后"整理所选"会自动带过来）/ 全部资料。
2. 在左栏勾选要处理的项（默认全不勾）。
3. 右栏选择**执行入口**与**外部执行方式**：
   - 没配置本机工具？选 **"手动复制"** → 点 **"复制整理指令"**，把指令粘到任何能访问这个库文件夹的 AI 工具（如网页版 Claude/ChatGPT 配合文件、或本机其他 CLI）。
   - 已配置 OpenCode CLI（见 [07 连接与分享](07_连接与分享.md)）？选本机工具 → 点 **"开始整理"**，任务自动传入，输出实时显示在页内。
4. 外部 AI 执行时只写 `wiki/` 下的知识文件，不会动你的原始资料。

## 第 4 步：核对结果

1. AI 执行完（本机模式进程自动结束；复制模式手动点 **"我已在外部执行，核对结果"**），整理页进入核对态。
2. 页面会列出**本次知识变化**（新增/修改/删除的 wiki 文件，与任务开始时的基线对比）。
3. 逐项核对后勾选，可填核对说明，点 **"确认完成这 N 项"**：
   - 全部成功：对应待整理记录被清除。
   - 有项在执行期间又变化了：自动保留在待整理清单，并提示"N 项有新变化，仍待整理"。
4. 未处理完可点 **"结束本任务，剩余继续待整理"**，或 **"放弃"**（两者都不清除任何记录）。

## 第 5 步：阅读知识

到**知识页**：目录栏默认只显示**源文档**（你放进去的资料）；打开 **"显示结构文件"** 开关后出现 AI 整理的知识目录（默认打开"知识首页" `wiki/index.md`）。正文里的 `[[链接]]` 和 `[来源: 文件名]` 可点击跳转；右侧"本页目录"快速跳章节。资料有新变更时，页面顶部会提醒"有 N 项资料变更尚未整理"。知识页完全只读，编辑源文档去资料页。

## 界面速查

| 位置 | 功能 |
|---|---|
| 标题栏库名按钮 | 切换/新建知识库 |
| `Ctrl+K` 全局查找 | 按文件名搜当前库，双击结果直达 |
| 侧边栏 | 知识 / 资料 / 整理 三个主入口 + 设置类页面 |
| 底部状态栏 | 待整理数量、本机任务状态（可点击跳整理页）、版本号 |
| `F5` | 知识页/资料页刷新（会重新扫描资料变更） |
| `Ctrl+S` | 编辑中保存（资料页） |
| `Esc` | 取消编辑（有草稿时先弹保存选择，资料页） |
