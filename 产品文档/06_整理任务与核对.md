# 06 整理任务与核对

整理页把"资料变更 → AI 整理 → 人工核对"做成可追溯的任务闭环。副标题：**把资料变更整理成可追溯的知识。**

## 6.1 三类任务（页签）

| 页签 | 任务 | 用途 |
|---|---|---|
| 更新知识 | 增量整理 / 全量整理 | 把资料变更或全部资料整理进 wiki |
| 提问分析 | 回答问题 / 对比主题 | 基于库内资料生成问答/对比分析页（结果也是知识文件） |
| 检查维护 | 检查知识质量 / 处理已删除资料的引用 | 质量体检（来源、矛盾、陈旧、孤立页）；生成引用清理计划 |

**处理范围**（"更新知识"页签）：待整理变更 / 所选资料 / 全部资料。全部资料说明固定提示："首次整理或主动全面重整理时使用；生成任务后会冻结本次资料版本。"

## 6.2 执行入口与访问方式

| 执行入口 | 说明 |
|---|---|
| 本机工具：OpenCode CLI | 检测/验证通过后点"开始整理"自动执行，无需粘贴 |
| 手动复制 | 复制完整指令到任意外部 AI |

**外部执行方式**：文件直接访问（AI 用本机文件权限读写库目录）/ MCP 连接（AI 通过 MCP 协议受控访问）。MCP 方式下"本机开始"不可用，只允许复制任务说明。

## 6.3 任务快照（生成任务时冻结）

点主按钮后，应用创建任务快照存到 `.llmwiki/tasks/{taskId}.json`，冻结内容：

- 每个处理项的资料 SHA256 与变更记录哈希；
- 规则版本（purpose.md + schema.md 联合哈希）；
- **wiki 基线**：当时 `wiki/` 全部文本文件的哈希；
- 由 PromptComposer 生成的完整任务指令（含边界与保护条款：禁改 `.changes.json`、`.llmwiki/`、`purpose.md`、`schema.md`、`wiki/log.md`；不转 Markdown 副本；不自行清除待整理记录）。

相同内容重复生成会**复用**已有未结束任务，不重复建单。任务状态机：

```text
已准备 → 已复制 → 待核对 → 部分确认 → 本次已确认
                        └──────────→ 已结束（仍有待整理）/ 已放弃
```

已结束任务保留最近 50 个 / 30 天。

## 6.4 本机执行流程

1. 前提：连接页完成该工具的**检测安装与登录 + 验证实际执行**（见 [07 连接与分享](07_连接与分享.md)）。
2. 点 **"开始整理 / 开始分析 / 开始检查"**，校验依次检查：已选库 → 已勾选项 → 提问已填 → 无运行中任务（**不排队**）→ 格式门槛（本机工具首轮只读文本类格式，Office/PDF/图片会被拦截并提示改用复制指令）→ 写权限（更新任务需连接页勾选"允许当前库目录写操作"）。
3. 任务说明经临时任务文件（OpenCode）传入真实进程；页内输出面板实时显示（上限 5000 行 / 1 MiB，超出提示"较早内容已省略"）。
4. **取消任务** → 5 秒后出现"强制结束本次进程"（二次确认；只结束归属可核实的进程）。
5. 进程结束 → 任务进入**待核对**；已写入的文件**不会自动回滚**。

## 6.5 复制执行流程

1. 点 **"复制整理指令"**（MCP 方式为"复制任务说明"）。
2. 到外部 AI 中执行；可先 **"预览完整指令"** 查看全文。
3. 回来在"未完成任务"列表点 **"我已在外部执行，核对结果"** 进入核对。

剪贴板失败时状态区出现"重试复制"（重试同一任务快照，不新建任务）。

## 6.6 核对与确认

进入核对态后：

1. 顶部提示 **"外部程序已结束，请核对结果"**；展开 **"本次知识变化"**：与任务基线对比出的 wiki 新增/修改/删除（`log.md` 标记为操作日志）。
2. 每个处理项自动标注核对状态：待核对 / 已核对 / **资料已不存在 / 资料内容有新变化 / 待整理记录已变化 / 删除记录已变化 / 已删除资料重新出现**——有异常的项禁用勾选（防误清）。
3. 勾选已核对项（**默认全不勾**），可填核对说明，点 **"确认完成这 N 项"**：
   - 只有"勾选 + 版本仍匹配"的项会从待整理清单移除；
   - 有新变化的项保留并警告"N 项有新变化，仍待整理"；
   - 全部确认 → 任务"本次已确认"；部分 → "部分确认"。
4. 出口：**结束本任务，剩余继续待整理**（运行中禁止结束）/ **放弃**——两者都不清除记录。

## 6.7 其他功能

- **导出任务包**（更多 ▾）：ZIP 含 `任务说明.md`（库根路径脱敏为 `<知识库根目录>`）+ `manifest.json` 清单；选"含本次资料与规则"再附源文件原字节与 purpose.md/schema.md。适合把任务带到另一台机器执行。
- **未完成任务 / 最近任务**：活动任务可直接继续核对或放弃；最近任务只读留档。
- **刷新待整理清单**：重扫资料差异；页头常显"待整理 N 项：新增 a、修改 b、删除 c"。
- 规则更新后旧指令不能照抄：页面会提醒"规则已更新……任务核对完成后请显式确认"。
