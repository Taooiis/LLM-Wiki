# 08 设置与帮助

## 8.1 应用设置

### 存储

- **知识库根目录**：输入或浏览选择，实时校验（250ms 防抖）：格式错误 / 目录可用 / 应用后创建 / 无权限 / 路径未变化，均就地显示不弹框。
- **应用路径**：需确认。只更换读取位置，**不搬迁、合并或删除原目录文件**；本机 AI 任务运行中不可应用；应用前会列出将被停止的运行中服务（浏览分享、HTTP MCP）。
- **恢复默认**：填回 `我的文档\LLM Wiki\wikis`。
- UNC 共享可用，但多设备同时维护同一库不受保护（详见 [03 数据存储](03_知识库与数据存储.md)）。

### 外观

- **深色 / 浅色** 两张主题卡，点击立即生效并记忆（默认深色）。深浅主题影响全部页面、弹框与通知。

### 关于

- 版本号；**检查更新**：请求 GitHub Releases（`api.github.com/repos/Taooiis/LLM-Wiki/releases/latest`）；有新版本时启动后台也会 Toast 提醒。应用内**不含自动下载安装**，需点"打开发布页"手动下载。
- "查看使用帮助"跳帮助页并可返回本页。

## 8.2 知识库设置

### 基本信息

- 库名、完整路径、目录可访问状态；打开文件夹 / 复制路径。
- **危险操作（永久删库）**：折叠区 → 输入完整库名解锁 → 红色确认弹窗。删除前自动停止绑定本库的浏览分享与 MCP；目标与结构页签有未保存草稿时会先拦下。"目标与结构"未保存草稿存在时不允许进入删除确认。

### 目标与结构（规则编辑）

左右两个编辑器：**目标与边界 purpose.md**（这个库为谁服务、回答哪些问题、不收什么）与 **组织规则 schema.md**（知识如何分类、标注来源、互链）。

- 状态徽章：未修改 / 未保存 / 保存中 / 保存失败 / 磁盘版本已变化，未写入 等。
- **载入默认模板**：替换当前草稿（确认弹窗；只进编辑区，不落盘）。
- **保存**：乐观锁校验。磁盘版本已被外部修改时不写入，提供 **载入磁盘版本**（确认后丢弃草稿）或 **另存草稿副本**（复制到剪贴板，原文件不动）。
- 保存成功后触发**规则提醒**："规则已更新，已有知识尚未按新规则核对"——在知识页、整理页与本页持续显示，直到点"确认已按新规则核对"（"稍后处理"只折叠当前版本）。
- 有未保存草稿离开页签会触发未保存保护。

## 8.3 使用帮助（内置）

左侧主题列表（`Ctrl+F` 筛选）+ 右侧正文。内置 8 个主题：

| 主题 | 内容 |
|---|---|
| 快速上手 | 唯一带"本机执行 / 手动复制"双页签的主题，6 步清单 |
| 日常资料管理 | 添加与覆盖、预览与编辑、回收站 |
| 整理与结果核对 | 准备任务、核对与确认、部分完成与结束 |
| 本机 AI 工具 | 配置与验证、权限与格式、仍需粘贴时 |
| 连接与分享 | 浏览分享、MCP 连接、客户端配置 |
| 存储与备份 | 更换根目录、主题与偏好、备份与恢复 |
| 认识弹框与通知 | 反馈层级、键盘与安全 |
| 常见问题 | 9 条问答 |

- 正文里的就地按钮（"资料页""整理页""去连接与分享"等）可直接跳转对应页面。
- **返回链路**：从其他页跳入帮助时，右上显示"返回 + 来源页名"，点击经未保存保护返回原页。
- 固定尾注："资料保持原格式；整理完成后，请核对来源并确认结果。"

## 8.4 反馈体系（弹框 / 通知 / 页内提醒）

- **弹框（ContentDialog）**：用于创建、确认与危险操作；危险按钮红色、初焦在安全侧。
- **Toast（右下角）**：成功 3 秒 / 信息 4 秒 / 警告与错误 8 秒；支持动作按钮（如"撤销""重试复制"）；2 秒内同内容去重。
- **页内提醒条（InfoBar）**：需要用户停留处理的持久信息（待整理、规则更新、扫描不完整、确认已保存但显示待刷新等）。
- **未保存保护**：所有编辑场景共用：切页、切库、关窗前弹 **保存并继续 / 放弃更改 / 留在此处**（Esc = 留在此处）。
