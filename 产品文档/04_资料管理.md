# 04 资料管理

资料页负责库内所有原始文件的管理。副标题固定提示：**原格式保存 · 不生成 Markdown 副本**。

## 4.1 页面布局

- 左栏（340px）：筛选框 + 类型下拉 + 资料列表 + 底部"已选操作卡"。
- 右栏：选中文件详情卡 + 文档工作区（预览/编辑）。
- 行内交互分离：**单击行 = 预览**；**复选框 = 勾选用于整理/回收**（两者互不代替）。

## 4.2 支持格式

"可添加"、"应用内预览"、"应用内编辑"、"AI 可读"是四件独立的事，逐格判断：

| 分类 | 扩展名 | 应用内预览 | 应用内编辑 | 本机 AI 可读 |
|---|---|---|---|---|
| 文本 | .md .markdown .txt .log | ✓ 全文 | ✓（≤1 MiB） | ✓ |
| 数据 | .json .jsonl .xml .yaml .yml .toml .ini | ✓ 全文 | ✓（≤1 MiB） | ✓ |
| 表格 | .csv .tsv | ✓ 全文 | ✓（≤1 MiB） | ✓ |
| 文档 | .docx .docm | ✓ 文字提取 | ✗ | ✗（未验证） |
| 表格 | .xlsx .xlsm | ✓ 文字提取 | ✗ | ✗（未验证） |
| 演示 | .pptx .pptm | ✓ 文字提取 | ✗ | ✗（未验证） |
| PDF | .pdf | ✓ 前 50 页文字 | ✗ | ✗（未验证） |
| 图片 | .png .jpg .jpeg .bmp .gif | ✓ 图片 | ✗ | ✗（未验证） |
| 旧版/其他 | .doc .xls .ppt .rtf .odt .ods .odp .wps .et .webp .tif .tiff .svg | ✗ 保持原格式 | ✗ | ✗ |

其他要点：

1. **单文件上限 20 MiB**（导入时校验）。
2. **应用内文本编辑上限 1 MiB**；超限提示用"打开原件"在系统程序中编辑。
3. Office 提取为临时内容，不落盘、不生成副本；xlsx 每表只提取前 200 行（超出标注"已截断"）；PPT 只提取文字与备注。
4. PDF 只提取文字（前 50 页），扫描件会提示"可能需要视觉读取或 OCR"。
5. 忽略规则：`.` 开头、`~$` 开头（Office 锁文件）、`node_modules`、含 `.tmp-`、白名单外的扩展名一律不显示。

## 4.3 导入与新建

- **添加文件**：系统多选对话框（按分类过滤）；同名冲突弹对照窗（现有文件 vs 本次文件的大小、修改时间），可选 取消本批 / 跳过同名 / 覆盖同名。覆盖前旧版本**先存入回收站**（kind=overwrite），备份失败则拒绝覆盖。
- **新建资料**：Markdown（.md）或纯文本（.txt）；文件名自动补扩展名，正文为空不能创建。
- 导入/新建成功后立即记入待整理变更（"新增"）。

## 4.4 预览

| 类型 | 预览表现 |
|---|---|
| Markdown / 文本 | 页内渲染或等宽文本，可直接编辑 |
| docx/xlsx/pptx | "内容预览（不代表完整版式）"，附未覆盖警告（图片/批注/图表未提取） |
| PDF | "PDF 文字内容预览（50/N 页）"，无文字时提示可能为扫描件 |
| 图片 | 页内图片显示；提示"图片内容不代表 OCR 已完成" |
| 其他格式 | 只读信息页："此格式保持原文件保存，可在系统程序中打开或导出" |

详情卡三个徽标：**已入库** / 预览能力 / **AI 读取未验证**（非文本格式）。

## 4.5 编辑与保存

1. 预览态点 **"编辑"** 进入编辑框（等宽字体，底部显示编码与保存状态）。
2. `Ctrl+S` 保存：带磁盘版本校验（乐观锁）。磁盘上文件已被其他程序改过时，提供三个出口：
   - **返回编辑**：继续改草稿；
   - **另存副本**：存为 `原名.副本-yyyyMMdd-HHmmss.ext`；
   - **载入磁盘版本**：丢弃草稿（二次确认）。
3. 保存保留原编码/BOM/换行；成功后记入待整理变更（"修改"）。
4. 任何跳转/切库/关窗前，未保存更改会弹统一对话框：**保存并继续 / 放弃更改 / 留在此处**。

## 4.6 导出与打开原件

- **导出文件**：另存为对话框，复制不覆盖。
- **打开原件**：用系统默认程序打开；提示"修改并保存原文件后，请返回应用刷新"——刷新（`F5`）会把差异记入待整理变更。

## 4.7 回收站

入口：资料页 **"更多 ▾ → 回收站…"**。应用自管回收站（`.llmwiki/trash/`），**不依赖系统回收站**。

- **移入回收站**：勾选后点"移入回收站"；可立即点 Toast 上的 **"撤销"** 恢复。文件正被本机 AI 任务使用时会拒绝移除。
- 恢复：同名时自动改名（`原名（恢复1）.ext`）或手动指定名称；恢复后按事实重新登记变更。
- **导出**：从回收站把文件复制出来。
- **永久删除 / 清空回收站**：内联红色确认，不可恢复。
- 覆盖保留的旧版本也在回收站里，恢复时登记为"新增"。
- 固定警告："回收站不是备份；整库删除或磁盘损坏会同时失去这里的内容。应用不会自动清理。"

## 4.8 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+F` | 聚焦筛选框 |
| `Ctrl+N` | 新建 Markdown 文档 |
| `Ctrl+S` | 保存编辑 |
| `F5` | 刷新并扫描源版本 |
