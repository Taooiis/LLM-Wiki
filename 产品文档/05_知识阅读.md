# 05 知识阅读

知识页是阅读界面，**完全只读**：AI 生成的知识（`wiki/`）与你的源文档（`raw/sources/`）都只能看、不能改。wiki 由 AI 维护；源文档要编辑去**资料页**。

## 5.1 页面布局

三栏：

1. **目录栏**（左，248px，可拖 220–320）：标题下的 **"显示结构文件"开关** + 虚拟化树 + 筛选框（`Ctrl+F`）。
   - **默认只显示源文档**：`raw/sources/` 下的文件扁平列表——你只需要关心放进去的资料。
   - 打开"显示结构文件"后追加 wiki 结构树：`wiki/index.md` 显示为 **"知识首页"**（Home 图标，置顶），目录显示中文别名：entities→实体、concepts→概念、sources→资料摘要、queries→问题分析、synthesis→综合分析、comparisons→对比分析。
   - `wiki/log.md` 不作为知识展示（它是操作历史）。
   - 开关状态会记住（应用级偏好），重启保留；展开/选中状态在切换开关和刷新时保留。
2. **阅读区**（中）：Markdown 渲染（可选中文本）、纯文本回落、图片预览、文档提取文本、或只读信息页。大标题 = 正文第一个 H1，下方等宽小字显示文件相对路径。
3. **本页目录**（右，150px）：解析 H1–H4 生成，点击滚动定位；窗口较窄时收起，用顶部 **"目录"** 按钮弹出菜单代替。

## 5.2 点击源文档与知识页

- **点源文档**：只读预览——md/txt 直接显示，图片就地解码，docx/pdf 提取文本显示，其余格式给只读信息（可用系统程序打开）。没有编辑按钮。
- **点知识页**：只读阅读。
- **`[[链接]]` Chip（↗ 名称）**：点击跳到目标知识页；目标不存在时置灰（提示"知识页尚未整理或已被移动"）；有多个同名候选时弹菜单逐项选择。
- **来源 Chip（来源：名称）**：点击跳到资料页并选中该来源文件；来源已删除时置灰。
- 页面顶部可能出现三类提醒条：
  - **待整理提醒**："有 N 项资料变更尚未整理" + **去整理**（"稍后处理"只折叠，新变更会再次出现）。
  - **规则更新提醒**："规则（purpose.md / schema.md）已更新到 xxxxxx，请核对现有知识是否仍符合新规则。" + 稍后处理 / 确认已按新规则核对。
  - **加载失败**（附重试）。

## 5.3 常用操作

标题右侧常驻按钮：

| 按钮 | 作用 |
|---|---|
| 目录 | 弹出本页标题菜单（窄窗口下的"本页目录"） |
| 刷新 `F5` | 重新扫描资料变更 + 重载知识目录 + 重开当前页 |
| 更多 ▾ | 解除保护 / 复制当前路径 / 打开知识库文件夹 |

## 5.4 只读边界与人工修订保护

- **知识页没有编辑入口**：不存在"手动修订知识"操作，Ctrl+S/Esc 编辑快捷键已移除。想让 AI 更新知识，去整理页执行整理任务。
- **人工修订保护机制保留**：旧版本中手动修订过的知识页仍受保护，AI 写入命中受保护版本会被拒绝（`MANUAL_REVIEW_REQUIRED`）。**更多 ▾ → "解除本页人工修订保护…"** → 确认弹窗（显示文件、相对路径、版本号）→ 解除的是**当前版本**的保护，AI 后续写入仍需通过路径与版本校验。新版应用不再产生新保护。

## 5.5 空状态

| 场景 | 显示 |
|---|---|
| 没有知识库 | "创建你的第一个知识库" + 新建按钮 |
| 有库有资料但还没整理 | "还没有整理出的知识" + 去整理 |
| 有库没资料 | "资料已准备好。整理成知识后，就能在这里阅读" + 去资料页 |
| 未选中文件 | "选择一个文件查看内容" |

空态覆盖层只在没有打开任何文件时显示；从目录点开文件后自动让位给正文。

## 5.6 快捷键

| 键 | 作用 |
|---|---|
| `Ctrl+F` | 聚焦目录筛选框 |
| `F5` | 刷新（扫描 + 重载 + 重开当前页） |
