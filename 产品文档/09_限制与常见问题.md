# 09 限制与常见问题

## 9.1 数值限制速查

| 限制 | 数值 |
|---|---|
| 单个资料文件 | ≤ 20 MiB |
| 应用内文本编辑 | ≤ 1 MiB（超出用"打开原件"） |
| xlsx 提取 | 每表前 200 行（超出标注截断） |
| PDF 预览 | 前 50 页文字 |
| 知识目录深度 | ≤ 8 层 |
| 本机任务输出缓冲 | 5000 行 / 1 MiB（超出丢最旧行） |
| 已结束任务保留 | 最近 50 个 / 30 天 |
| MCP 读单文件 / 单段 | 20 MiB / 64 KiB |
| MCP 单次写入 | ≤ 4 MiB，仅 wiki/ 下 .md/.txt |
| MCP 搜索 | 默认 20 条、上限 50 条；最多扫 5000 文件；片段 ≤200 字符 |
| 路径长度 | ≤ 260 字符 |
| 浏览分享端口 / MCP 端口 | 默认 8765 / 8766 |
| 检测/验证超时 | 检测 8–10 秒，实际执行探测 90 秒 |

## 9.2 AI 不可触碰清单

任务指令层面禁止，MCP 策略层面硬拒绝：

- `.changes.json`、`.llmwiki/` 全部（任务、回收站、回执等内部状态）——对 MCP 完全不可见
- `purpose.md`、`schema.md`（规则文件）
- `wiki/log.md`（操作历史）
- `raw/sources/` 下的一切（资料只读，不可修改/删除/移动）
- 人工修订保护中的知识页版本（旧版手动修订产生；需人工解除，新版应用不再新增）

另有：MCP 无删除类工具；MCP 写入不产生待整理变更，但会记入操作历史。

## 9.3 MCP 错误码

错误消息格式为 `CODE: 详情`：

| 错误码 | 含义 |
|---|---|
| KB_NOT_FOUND | 库不存在或未授权 |
| PATH_NOT_ALLOWED | 路径越界 / 非法 / 内部文件 |
| READ_ONLY_MODE | 服务处于只读档 |
| WRITE_NOT_ALLOWED_PATH | 写入目标不在允许范围 |
| VERSION_CONFLICT | 版本不匹配（文件已被他人修改） |
| VERSION_REQUIRED | 覆盖缺少 expected_version |
| FILE_TOO_LARGE | 超出大小上限 |
| FILE_NOT_FOUND | 文件不存在 |
| MANUAL_REVIEW_REQUIRED | 目标页有人工修订保护（旧版手动修订产生） |
| FORMAT_NOT_SUPPORTED | 该资料格式不支持读取（如 PDF/图片经 MCP） |
| SOURCE_READ_FAILED | 资料读取失败 |
| SERVICE_UNAVAILABLE | 服务不可用 |

## 9.4 常见问题

**Q1：导入资料后知识没有变化？**
正常。资料变更先进入"待整理"，需要到整理页发起任务、执行并核对确认后才会变成知识。

**Q2：任务一直停在"待核对"？**
应用不会替你确认。本机进程结束只代表进程退出，需要你勾选已核对项并点"确认完成"。复制模式下要手动点"我已在外部执行，核对结果"。

**Q3：为什么本机执行不了 Word/PDF？**
本机工具首轮只验证了文本类格式的读取；Office/PDF/图片标记"AI 读取未验证"，会被格式门槛拦截。改用"复制指令"（把文件交给支持该格式的 AI），或只勾选文本资料。

**Q4：PDF/Word 预览不完整？**
预览是提取的文字（PDF 前 50 页、xlsx 每表 200 行、PPT 只有文字与备注），不代表完整版式。完整内容用"打开原件"。

**Q5：AI 改坏了知识页怎么办？**
变更基于版本哈希：可从任务"本次知识变化"核对；文件系统层面可自行备份/还原（备份整个库文件夹）。受人工修订保护（旧版产生）的页面 AI 无法静默覆盖。

**Q6：误删资料能恢复吗？**
回收站可恢复（同名自动改名）；覆盖旧版本也在回收站。但回收站不是备份——永久删除/清空/删库不可恢复。

**Q7：换了根目录，原来的库不见了？**
切换根目录只换读取位置，不搬数据。把路径改回原位置即可看到原库。

**Q8：手机怎么看库？**
连接与分享 → 浏览分享 → 启动，手机访问 `http://llmwiki.local:8765/`（或局域网 IP），输入 4 位访问码。只读。

**Q9：规则改了之后要注意什么？**
保存规则后会出现"规则已更新"提醒：旧任务指令不能照抄，重新生成任务；核对完成后点"确认已按新规则核对"消除提醒。

**Q10：关掉桌面应用，MCP 还能用吗？**
不能。HTTP MCP 随桌面应用一起停止，重新打开应用并开启连接后才恢复。

**Q11：多台电脑能共用一个库吗？**
可以把根目录指向共享目录，但应用不做多机协调——避免同时维护，修改者负责重新整理。UNC 共享不等于只读。
