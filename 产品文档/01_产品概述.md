# 01 产品概述

## 1.1 产品定位

LLM Wiki 是面向单机的**本地资料与知识工作台**：资料进来不改动、不转格式；AI 在明确边界内把资料整理成知识；整理结果必须经过人工核对才算数。应用本身不内置聊天、不调用在线大模型接口——所有 AI 能力都来自用户自己配置的外部工具（OpenCode CLI，或任意 MCP 客户端）。

## 1.2 核心工作闭环

```text
资料（原格式保存）
   ↓  添加/编辑/删除时自动记录
待整理变更（.changes.json，带 SHA256 指纹）
   ↓  整理页生成任务快照（冻结范围、资料哈希、规则版本、wiki 基线）
整理任务（复制指令 / 本机 CLI 执行 / MCP 连接）
   ↓  外部 AI 只写 wiki/ 下的知识文件
知识变化（与任务基线对比得出）
   ↓  人工逐项勾选核对，确认后才会清除对应待整理记录
知识（wiki/ 下互相链接的 Markdown 页）
```

关键点：

1. **复制不是执行完成**。应用无法确认外部 AI 是否真的完成，所以进程结束或复制成功都不产生任何确认，只有人工勾选 + 版本比对后才移除待整理记录。
2. **AI 写入有边界**。任务指令明确禁止 AI 触碰 `.changes.json`、`.llmwiki/`、`purpose.md`、`schema.md`、`wiki/log.md`；MCP 通道还用策略硬限制写入路径。
3. **人工修订保护**。受保护的知识页版本，AI 覆盖会被拒绝（`MANUAL_REVIEW_REQUIRED`），需人工解除；保护由旧版本的手动修订产生，新版应用不再产生新保护。

## 1.3 技术形态

| 项目 | 形态 | 职责 |
|---|---|---|
| `Wpf UI`（LLM Wiki） | WPF 桌面主程序 | 全部界面、浏览分享、HTTP MCP 服务 |
| `LlmWiki.Core` | 类库 | 知识库/资料/任务/变更/回收站/规则等服务，MCP 能力实现 |

技术栈：.NET 10 + C# + WPF + WPF-UI 4.3.0 + MVVM，全 WPF，无 WebView2。

## 1.4 页面总览

| 页面（侧边栏入口） | 功能 |
|---|---|
| 知识 | 源文档目录 + 只读阅读区："显示结构文件"开关查看 AI 整理出的知识页，解除保护 |
| 资料 | 资料库管理：导入/新建、类型筛选、预览与编辑、回收站 |
| 整理 | 任务向导：三类任务 × 三种范围 × 四种执行入口，核对确认闭环 |
| 连接与分享 | 浏览分享（局域网只读页）、本机 AI 工具配置与验证、MCP 连接管理 |
| 知识库设置 | 库基本信息、规则文件（purpose.md / schema.md）编辑、永久删库 |
| 应用设置 | 知识库根目录、深浅主题、版本与更新检查 |
| 使用帮助 | 内置 8 个主题的操作教程，可从各页跳入并返回原页 |

主窗口还有：标题栏**知识库切换**按钮（当前库名 / "未选择知识库"）、**全局查找框**（`Ctrl+K`，只搜文件名，结果按资料/知识分组，双击直达）、底部状态栏（待整理数量、本机任务状态、版本号）。

## 1.5 功能边界（设计原则）

1. **原格式保存**：资料按原始字节存放在 `raw/sources/`，不生成 Markdown 副本；应用内预览/编辑只是视图，不落盘。
2. **变更驱动**：每次导入、编辑、删除、扫描发现的差异都记入库根 `.changes.json`；"整理"就是处理这些变更。
3. **任务快照**：生成任务时冻结资料哈希、规则版本和 wiki 基线；执行期间资料再变化会被检出并阻止确认。
4. **确认才清账**：只有人工勾选且版本仍匹配的待整理项才会被移除；有新变化的项自动保留（"stale"）。
5. **回收站自管**：删除资料进应用自己的回收站（`.llmwiki/trash/`），不依赖系统回收站；覆盖旧版本也先入回收站。

## 1.6 术语表

| 术语 | 含义 |
|---|---|
| 知识库（KB） | 磁盘上一个文件夹，含资料、知识、规则与内部状态 |
| 资料（Source） | `raw/sources/` 下的原始文件，保持原格式 |
| 知识（Knowledge） | `wiki/` 下的 Markdown 页面，由 AI 整理或人工修订产生 |
| 规则 | 库根的 `purpose.md`（目标与边界）+ `schema.md`（组织规则），AI 执行前必须读取 |
| 待整理变更 | `.changes.json` 中记录的资料新增/修改/删除 |
| 整理任务 | 一次整理的快照与状态机（已准备 → 已复制 → 待核对 → 已确认…） |
| 执行入口 | 任务交给 AI 的方式：本机工具（OpenCode CLI）、手动复制 |
| 访问方式 | 外部 AI 访问库的方式：文件直接访问 / MCP 连接 |
| 人工修订保护 | 受保护的知识页版本 AI 不能静默覆盖；新版应用不再产生新保护 |
| 任务包 | 导出的 ZIP（任务说明 + 清单，可选含资料与规则） |
| MCP | Model Context Protocol；应用提供 HTTP 接入（默认只读，可切写入档） |
| 浏览分享 | 局域网内手机/平板用浏览器只读查看知识库 |
