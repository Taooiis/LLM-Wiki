# LLM Wiki 产品文档

LLM Wiki（本地资料与知识工作台）是一款 Windows 桌面应用：把原始资料按**原格式**保存在本地知识库中，借助外部 AI（本机 CLI 工具、复制任务或 MCP 连接）把资料整理成互相链接的 Markdown 知识页，再由人工逐项核对确认，形成可追溯的知识沉淀闭环。

> 本文基于实际代码整理（feature/wpf-ui-migration 分支，2026-10-31），描述程序当前真实具备的功能与限制。与 `设计文档/` 分工：设计文档约束"应该是什么"，产品文档记录"现在是什么"。

## 三句话理解本产品

1. 资料永远保持原格式（PDF、Word、表格、PPT、文本、图片……），应用不生成、不要求 Markdown 副本。
2. AI 只负责"整理"，写入范围被约束在 `wiki/` 知识目录；是否采纳由人工勾选核对后才生效。
3. 一切变更可追溯：资料变更、任务快照、AI 写入都带 SHA256 版本指纹和操作日志（`wiki/log.md`）。
