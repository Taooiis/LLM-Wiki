# 07 连接与分享

"连接与分享"页管理三类对外能力，各自独立启停：**本机 AI 工具**（CLI 自动执行）、**浏览分享**（局域网只读页）、**MCP 连接**（受控协议访问）。服务范围绑定启动时的知识库，切换当前库不会改变正在运行的服务。

## 7.1 本机 AI 工具（AI 工具页签）

本机工具类型：**OpenCode CLI**。适配器采用注册表模式：新 CLI 实现适配器接口并在注册表登记后，下拉与执行流程自动扩展。

### 配置步骤（CLI 工具）

1. **工具类型**：OpenCode CLI（来自注册表）。
2. **程序路径**：**自动查找**（PATH 与常见安装目录，如 `~\.opencode\bin\opencode.exe`）或**浏览**手动选择。只接受原生 `.exe`，不用 .cmd/.ps1 包装。路径每改动一次，旧检测/验证立即过期。
3. **检测安装与登录**：运行 `--version`、`run --help`，并通过只读命令 `opencode models` 拉取可用模型列表；右侧"检测与能力"卡逐项显示 安装/登录/非交互执行 结果。
4. **模型**：下拉选择任务使用的模型，留空 = 跟随 OpenCode 自己的默认配置；列表来自 `opencode models`（只读，不含凭据），选择随档案保存（`modelId` 字段），执行时经 `--model` 参数传递。
5. **验证实际执行**：在隔离临时目录真实跑一次只读小任务（90 秒超时，使用当前所选模型）。⚠ 会消耗所选工具的账号额度。
6. **权限**：只读 / **允许当前库目录写操作**（开启需确认——这是操作系统文件权限，不能强制限制为只写 wiki/）。
7. **保存并使用**。就绪标准 = 安装 + 登录 + 非交互执行 + 实际执行验证全部通过。

### 执行机制

| 项 | OpenCode CLI |
|---|---|
| 启动命令 | `opencode run "…" --format json [--model {模型ID}] --agent {plan\|build} --file {任务文件}`（工作目录即库根） |
| 任务传入 | `.llmwiki\attempts\{id}.task.txt`（用后即删） |
| 只读约束 | `--agent plan` + 进程内权限变量（edit/bash 等全部 deny，仅限本进程） |
| 会话 | 每次全新进程，无会话复用 |

通用规则：

- **单任务**：运行中不能再启动（不排队）。
- **输出回执**：每次执行存 `.llmwiki\attempts\{id}.json`（退出码、沙箱模式、时间）。
- **取消两段式**：先请求取消，5 秒后可强制结束（强制前核实进程归属，防误杀其他会话）。
- **格式门槛**：本机执行只接受文本类资料（md/txt/csv/json 等）；Word/PDF/PPT/图片未验证，会提示改用复制指令。
- **凭据隔离**：账号、模型由外部工具自己管理；本应用不读取认证文件、不保存任何密钥。

## 7.2 浏览分享（浏览分享页签）

让同一局域网的手机/平板用浏览器**只读**查看当前知识库。

1. 设端口（默认 **8765**，0 = 系统分配）→ 点 **"启动浏览分享"**。
2. 分享开启时自动生成 **4 位数字访问码**（每次开启重新生成；"更换访问码"会使旧码与已登录会话立即失效）。
3. 访问方式：
   - 局域网地址卡列出的 `http://{局域网IP}:{端口}/`；
   - 支持 mDNS：`http://llmwiki.local:{端口}/`（端口被占用时自动降级为 IP 访问）；
   - "打开地址"在本机浏览器打开。
4. 首次访问输入访问码，之后浏览器保持登录（HttpOnly cookie）。
5. 访客能做什么：
   - **允许**：浏览目录树、页内预览 md/txt、下载原文件（docx/xlsx 等点击即下载）；
   - **不允许**：上传、编辑、删除、改配置（服务端只有 GET 白名单路由，没有写 API）。
   - 可见范围：仅 `raw/sources/` 受支持格式（源文档）；隐藏点文件不显示。
6. 停止：点 **"停止浏览分享"**，旧访问码立即失效。
7. 注意：分享范围绑定**启动时的库**；换库需停止后重开（页面会提示并提供"停止并更换分享范围"）。

## 7.3 MCP 连接（AI 工具页签底部）

MCP（Model Context Protocol）让任意 MCP 客户端（Claude Desktop、其他 IDE/Agent 等）通过 HTTP 受控访问知识库：

### HTTP MCP（桌面应用内开启）

1. 点 **"开启只读连接"**：服务跑在 `http://127.0.0.1:8766/mcp`（默认端口 8766），绑定启动时的库。
2. **写入**：默认只读。点"开启写入"需确认——写入范围被策略硬限制为 `wiki/` 下的 .md/.txt，不能动资料/规则/日志，不能删除；**重启应用后恢复只读**。
3. **访问令牌**：读取令牌必配；写入档另有写入令牌。令牌 32 字节随机，DPAPI 加密存储；"重新生成"使旧令牌立即失效；界面默认掩码显示。
4. **切换局域网监听**：默认仅本机；开放需确认（仅限可信网络，客户端仍需令牌）。
5. **客户端配置**：一键复制 JSON（HTTP remote 条目含端点与令牌头）。
6. **最近受控调用**：显示最近 20 条工具调用（时间、工具名、成败）。

### MCP 暴露的能力

| 类别 | 内容 |
|---|---|
| 工具 7 个 | list_knowledge_bases、list_tree、read_file（64 KiB 分段续读）、read_source_content（Office 临时转换提取）、search_content、get_pending_changes、write_wiki_file（仅 HTTP 写入档） |
| 提示卡 7 张 | boundary、batch_ingest、incremental_ingest、query、lint、compare、clean（与整理页同一套任务指令） |
| 资源 URI | `wiki://{库}/purpose.md`、`schema.md`、`index`、任意可读文件（逻辑 URI，不暴露本机路径） |

### 安全策略要点

1. 每个会话只绑定一个授权库；不返回任何本机绝对路径。
2. 拒绝绝对路径、`..`、盘符、符号链接逃逸；`.` 开头的内部文件（`.changes.json`、`.llmwiki/`）一律不可读。
3. 写入：仅 `wiki/` 下 .md/.txt，禁写 `wiki/log.md`；覆盖必须带 `expected_version`（SHA256），新建必须显式 `expected_absent=true`；命中**人工修订保护**返回 `MANUAL_REVIEW_REQUIRED`。
4. 版本冲突（`VERSION_CONFLICT`）防止覆盖别人刚写的内容；MCP 写入成功会自动记入 `wiki/log.md`，但**不产生待整理变更**。
5. 上限：读单文件 20 MiB、单段 64 KiB、写单次 4 MiB、路径 ≤260 字符。完整错误码见 [09 限制与常见问题](09_限制与常见问题.md)。
