## 1. 全局框架

### 1.1 导航结构 ✅
- 左侧 NavigationView：首页 / 源文档 / 目录浏览 / 工作流 / 分享 + 底部（Settings / 配置 / 小白指南）
- 交互：点击切换页面；当前项紫色渐变胶囊高亮 🆕；工作流项带待处理变更数量徽标 🆕
- 窗口：1100×650 起，Mica 暗色背景，圆角窗口

### 1.2 主题 ✅/❓

- Settings 页保留 Light/Dark 切换：点单选即时生效并记住

### 1.3 全局反馈 ✅
- 成功/失败提示统一走底部 Snackbar（绿色成功 / 红色失败，2.6s 自动消失）
- 未捕获异常：记 `logs/crash.log`，不弹崩溃框

## 2. 知识库管理（首页）

### 2.1 统计卡行 🆕❓
- 4 张统计卡：知识库数 / 源文档数 / 待处理变更数 / 存储状态（当前路径摘要）
- 交互：数据随建库/删库/选库/文件操作即时刷新；待处理变更 >0 时数字旁出红色"需重新 Ingest"小标

### 2.2 新建知识库 ✅🔧
步骤：
1. 右侧"新知识库名称"框输入名字（仅中文/英文/数字/下划线/中划线）
2. 点"新建"
交互：
- 名字非法 → 红色 toast"知识库名只允许中文、英文、数字、下划线、中划线"，不崩溃 🔧
- 与现有库重名 → toast"库已存在，已为你选中：xxx"（幂等补骨架，数据无损）🔧
- 成功 → toast"已创建知识库：xxx" + 列表刷新 + **自动选中新库** + 库路径行更新
- 建库骨架：purpose.md、schema.md、raw/sources|assets|original、wiki/entities|concepts|sources|queries|synthesis|comparisons

### 2.3 切换/删除 ✅
- 切换：点列表项即选中 → 库路径行更新 → 全部页面联动刷新（源文档/目录/工作流/配置）
- 删除：点"删除" → 确认弹窗"确定要删除知识库 xxx 吗？此操作不可恢复" → 确认后删除 + toast + 选中回退到首个库

### 2.4 搜索 ✅
- KB 搜索框、文件搜索框各自独立、输入即时本地过滤（不回读磁盘）

### 2.5 文件预览/保存 ✅🔧
- 点文件列表项 → 预览区加载内容 → "保存"按钮可点
- 保存：写回成功 toast"已保存"；**失败 toast"保存失败：原因"**（不再虚假成功）🔧

## 3. 源文档

### 3.1 列表 ✅🔧
- 只列 `raw/sources/` 下受支持类型文件；每行：**类型图标**（📝md/txt 📊xlsx 📕pdf 🌐html…）🆕 + 文件名 + 大小/时间副文本 🆕
- 点行 → 预览区加载（🔧 已修：此前读错路径预览恒空）+ "编辑"按钮启用

### 3.2 新建文档 ✅
1. 点"＋ 新建" → 弹编辑器（新建模式：文件名输入框可见）
2. 填文件名（自动补 .md）+ 写内容 → 点"创建"或 Ctrl+S
- 文件名空 → 弹窗内红字提示，不关闭
- 成功 → 落盘 `raw/sources/` + 列表刷新 + 自动选中新文件 + toast"已创建：xxx，去工作流页重新 Ingest 该文档"

### 3.3 编辑 ✅🔧
1. 选中文件 → 点"编辑" → 弹编辑器（Exist 模式，顶部显示完整相对路径）
2. 改内容（标题栏出现 ● 未保存）→ 保存
- 保存成功 → toast + 待处理变更自动新增一条 + `wiki/log.md` 追加记录
- 🔧 已修：此前点列表项读不到内容、弹窗空白

### 3.4 上传 ✅/❓
- 点"上传" → 系统文件对话框（多选）→ 文件落 `raw/sources/`
- 现行为：.docx/.xlsx **转成 .md** 入库、原件存 `raw/original/`
- ❓ **待确认（见 §10 多文件类型）**

### 3.5 删除 ✅
1. 选中文件 → 点"删除" → 确认弹窗 → 确认
- 源文档删除 → 记变更（动作=删除）+ log.md 记录 + 列表刷新 + 预览清空

### 3.6 待处理变更 ✅
- 自动记录：新增/修改/删除（含时间），同文件同哈希去重
- 勾选状态在列表滚动回收后不丢 🔧
- "标记已处理"：清除勾选项；"生成选中 Ingest"：见 §5.4

## 4. 编辑器弹窗（全站统一）✅

| 交互 | 行为 |
|------|------|
| 打开 | Exist 模式：标题"编辑"+ 顶部完整路径；New 模式：标题"新建文档"+ 文件名输入框 |
| 改内容 | 标题栏出现红色"● 未保存" |
| Ctrl+S | 等效点保存，直接落盘 |
| 保存 | 写盘 → 清除 ● 标记 → toast；失败 → 红字留在弹窗内（**改进项 🆕❓：失败不关弹窗，防丢稿**） |
| Esc/关闭 | 有未保存修改 → MessageBox"有未保存的修改，确定关闭？" |
| 文件名（New） | 空 → 红字"文件名不能为空"不关闭；自动补 .md 后缀 |
| 样式 🆕 | 暗色等宽编辑区、紫色渐变保存按钮、路径用等宽字体 |

## 5. 工作流（7 张卡）✅

### 5.1 卡片通用 ✅🔧
- 进页面即按当前库生成；KbPath 用真实存储路径（🔧 此前硬编码）
- 每卡右上"📋 复制" → 剪贴板 + toast"已复制：卡名"（🔧 此前按钮全失效）
- Query/Compare 卡内带输入框：**复制时按输入重新生成**提示词

### 5.2 七张卡 ✅
| 卡 | 输入 | 生成内容 |
|----|------|---------|
| ① 边界说明 | 无（含文件清单） | Agent 接入说明（库名+绝对路径+三文件摘要+目录约定） |
| ② Ingest（批量） | 页头文件名行（逗号分隔/留空=全部）+ "生成提示词"按钮 🔧 | 指定文件或全量入库提示词 |
| ③ Ingest（增量） | 无 | 仅处理 .changes.json 待处理变更 |
| ④ Query | 卡内问题框 🔧 | 带来源引用的问答提示词 |
| ⑤ Lint | 无 | 矛盾/陈旧/孤立页/缺口检查 |
| ⑥ Compare | 卡内主题框 🔧 | 对比页生成提示词 |
| ⑦ Clean（级联清理） | 无 | 删除文档的 wiki 引用清理 |

### 5.3 路径归一化 ✅🔧
- 输入/变更里的 `raw/sources/` 前缀自动剥离，提示词不再出现双前缀

### 5.4 待处理变更 → Ingest ✅🔧
1. 源文档页勾选变更 → 点"生成选中 Ingest"
2. 未勾选 → toast"请先勾选要处理的变更" 🔧
3. 自动跳工作流页 → Ingest 框已填文件名 → 提示词已生成
4. 执行完回源文档页"标记已处理"

## 6. 目录浏览 ✅🔧
- 进页加载当前库目录树；页头显示"当前库: xxx"
- 点任意 .md/.txt 文件（含 `wiki/` 子目录）→ 右侧预览 + 保存按钮可用
- 保存：**写回原相对路径**（🔧 此前会把子目录文件写错到库根——数据破坏级，已修）
- md/txt 可编辑，其他类型只读预览 🆕❓

## 7. 配置

### 7.1 存储路径 🔧
| 步骤 | 交互 |
|------|------|
| 手输路径 | 输入即时验证（🔧 此前不触发验证，保存的是旧值=“改不了”的根因），按钮状态即时跟随 |
| 点"浏览" | FolderPickerDialog（桌面/文档/程序目录直达、地址栏前往、磁盘列表、UNC 局域网浏览） |
| 点"保存" | 校验 → 建目录 → 写 config.json → **立即全局生效**（库列表/文件读写/树/工作流跟随）🔧 + 重载库列表 |
| 点"恢复默认" | 回 %APPDATA%\LLM_Wiki\wikis 并立即生效 🔧 |
| 非法路径 | 输入框下方红字 + 保存按钮禁用 |

### 7.2 purpose / schema ✅
- 两张编辑卡（🔧 schema 编辑器此前缺失）：改 → 保存 → toast + 记 log

## 10. 多文件类型支持 🆕❓（待确认）

**目标：原样保留文件类型，不再统统转成 md。**

### 拟定分类（设计稿采用方案）
| 类型 | 处理 | 编辑 | 图标 |
|------|------|------|------|
| .md / .txt | 直接入 `raw/sources/` | ✅ 应用内编辑器 | 📝 |
| .docx / .xlsx / .pdf | 原文件直存 `raw/sources/`（**不再转 md**） | ❌ 只读存档，"打开"调系统默认程序 | 📊📕 |
| .csv / .json / .html / .py 等文本类 | 直接入库 | ✅ 文本编辑器 | 🌐 |
| 其他类型 | 上传时拒绝并提示 | — | — |

### 交互变化
- 上传：白名单内任意类型直接存原件（.docx/.xlsx 不再自动转 md、不进 raw/original）
- 列表：全部类型混排显示，非可编辑类型带"只读"徽标 + "打开"按钮
- 删除：全部白名单类型可删
- Ingest 提示词：对只读类型注明"二进制/Office 文件，由 Agent 自行解析（如 pandoc/office 库）"
- ❓ 请确认：a) 白名单清单；b) .docx/.xlsx 是否还需要"同时生成 md 副本"选项；c) "打开"用系统默认程序是否符合预期
