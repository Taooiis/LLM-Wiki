# 02｜资料与知识工作区

## 1. 两个区域的关系

“资料”是输入，“知识”是外部 AI 整理后的输出。两页保留，因为对象和操作权限不同；合并底层文档组件，取消同一文件在多处重复维护的入口。

| 对象 | 展示位置 | 默认操作 | 写入影响 |
|---|---|---|---|
| raw/sources/*.md、*.txt | 资料 | 预览、编辑、删除 | 记录源变更和日志 |
| docx/xlsx 原格式资料 | 资料 | 查看文件信息、支持时预览、打开/导出原文件、重新上传、删除 | 操作 raw/sources/ 下的源文件，记录源变更 |
| wiki/ 下的知识页 | 知识 | 阅读、链接跳转、复制路径 | 默认不写入 |
| wiki/log.md | 整理中的“查看变更日志” | 只读 | 仅既有日志服务追加 |
| purpose.md、schema.md | 知识库设置 | 查看、编辑 | 沿用配置变更记录规则 |
| .changes.json 等内部文件 | 普通列表隐藏 | 由业务服务维护 | 禁止作为普通文档编辑 |

## 3. 添加资料

“添加文件”使用系统多选文件选择器；若现有拖拽可用则保留。当前支持 md/txt/docx/xlsx，所有支持类型都按原格式保存，不强制 Markdown。PDF、doc/xls、图片等是否支持是独立能力，本次不因取消转换就宣称全部格式已支持；不支持时提示“此类型暂不支持添加”。

处理列表逐项展示“等待 / 保存中 / 已添加 / 已跳过 / 失败”。按原字节保存文件，不做上传转码或 Markdown 转换。先完整写入临时文件并校验，再提交目标；失败不留下半文件，覆盖失败保留之前有效版本。无真实百分比时只显示阶段。

重名先列冲突文件，让用户选“覆盖同名 / 跳过同名 / 返回”；可只对本批应用同一选择。覆盖提示“将替换现有资料，替换后需要重新整理知识”。非冲突文件与冲突文件的执行范围在提交前明确。

单文件上限 20 MiB（20,971,520 字节），多选按文件逐项提交。底层请求体上限需为协议封装预留空间，批次总量不能误当单文件上限；接入前按第 11 章适配传输。

完成后保留结果摘要，例如“已添加 3 份，失败 1 份”；失败条目提供重试。主后续操作“整理新增资料”，次操作“继续添加”。不自动执行外部 AI。

## 4. 非文本源文件展示与操作

- Word、Excel 文件直接保存为 raw/sources/需求说明.docx、raw/sources/销售明细.xlsx，一份上传对应一个原格式文件。
- 列表显示真实文件名与类型；预览可用时显示原文件预览，没有可用预览器时显示文件信息及“打开原文件 / 导出文件”，不阻止添加或整理。
- 预览或 AI 读取需要的临时内容提取仅在读取时进行，不保存为资料 Markdown，不替代原文件；不因预览失败把添加标成失败。
- 桌面文本编辑器只编辑受支持的文本类型。Word、Excel 用系统关联程序打开，不用文本框读写二进制文件。打开前提示“修改并保存原文件后，请返回应用刷新”。
- 外部编辑后，通过文件监测触发扫描，启动、进入资料页、刷新与确认前也扫描；按第 11 章持久指纹基线检测应用关闭期间的变化，排除 Office 锁文件。扫描不完整不判删除。
- “移入回收站”将所选源文件从活动目录移至库内隐藏回收站，不执行历史副本级联删除；可恢复，已有知识仍需引用清理。
- 重传先暂存并验证，把旧文件保留为回收站“覆盖前版本”，再替换同名源文件；不能安全保留旧版本则拒绝覆盖。添加、导出保持原字节；用户主动编辑保存才改变内容。
- 历史 raw/original 与历史 Markdown 衍生文件只作兼容展示，不自动移动、转换或删除；身份与变更切换见第 07、10 章。

## 5. 新建与编辑

“新建资料”菜单只有 Markdown、纯文本；默认为 Markdown。在右侧工作区输入文件名和正文，“创建资料”为主操作。缺少后缀按选择类型补齐，非法名和重名就地提示。未成功创建前不产生空文件。

文本选中后默认预览，点击“编辑”进入原位编辑；工具栏显示“未保存 / 保存中 / 已保存 / 保存失败”。支持现有的预览切换能力；分屏不是首轮必做。Ctrl+S 保存，取消走统一保护。无修改保存禁用；成功后继续编辑，点“完成编辑”回预览；保存中防重复，失败保留草稿，细则见第 11 章。

移入回收站前先处理编辑草稿；保存失败或取消则不移除。可恢复移除不再额外弹删除确认，成功后提供“撤销”；批量范围和隐藏选择数量提前显示，失败逐项说明。永久删除、整库删除仍需危险确认。资料页更多菜单提供“回收站”，恢复冲突与变更规则见第 12 章。

## 6. 资料选择与整理跳转

复选框选择与行单击预览分开。筛选后保留已选项，并显示“已选 5 项，其中 2 项被筛选隐藏”，避免暗中丢失或误删。切库清空选择。

“整理所选”携带当前库和稳定的相对路径进入整理页，范围自动为“所选资料”，不要求再填逗号文件名。按钮在无选择时禁用。跳转期间文件被删除时先提示缺失项，可移除缺失项后继续。

## 7. 知识页线框与默认入口

```text
知识                              [查找文件] [刷新] [打开文件夹]
产品研究 · 3 项资料变更尚未整理                         [去整理]
┌────────────────────────┬────────────────────────────────────────────┐
│ 筛选知识目录…          │ 产品概览                       [复制路径] […]│
│ ▼ 知识首页             │ wiki/overview.md                            │
│ ▼ 概念                 ├────────────────────────────────────────────┤
│   业务模型             │ Markdown 正文、表格与代码块                  │
│ ▼ 实体                 │ [[业务模型]] 可点击                          │
│ ▼ 资料摘要             │                                            │
│ ▷ 分析与对比           │ 来源：需求说明.docx [查看资料]                │
└────────────────────────┴────────────────────────────────────────────┘
```

首次打开默认选 wiki/index.md，缺失则尝试 overview.md；只有初始模板骨架且没有其他知识页时也视为尚未整理，按第 11 章模板哈希判定；没有知识时根据是否已有资料显示“添加资料”或“开始整理”。不要求新增数据库或自建知识首页文件。

目录使用中文分类别名，但不重命名磁盘目录：entities→实体、concepts→概念、sources→资料摘要、queries→问题分析、synthesis→综合分析、comparisons→对比。详情与复制路径始终使用真实相对路径。

Wiki 链接按现有解析能力解析相对目标；同名歧义展示候选路径；不存在显示“目标页面不存在”。来源标记能准确映射时提供“查看资料”，映射不可靠则只展示原引用，不猜测跳转。删除资料后的引用显示“来源已移除”，提供整理入口。

## 8. 高级手动修订

默认工具栏无“编辑”。更多菜单“手动修订知识…”说明“此内容通常由 AI 维护，手动修改不会更新源资料，后续整理应先核对人工内容”。显式进入后复用编辑器、版本校验、未保存保护；保存后记录手工版本保护。MCP 不可静默覆盖，文件直读通过指令提醒，具体见第 11 章。

只允许原服务允许的 wiki Markdown/TXT 文件；日志和系统文件保持只读。修订写回原相对路径，登记操作日志但不伪造成源资料待整理项。不新增知识页删除入口；清理仍通过维护流程计划后在本机确认。

高级手动修订正式纳入本版，仅作用于允许的知识文本；需同时实现版本保护和 MCP 冲突拒绝，不能只开放编辑按钮而跳过权限规则。

## 9. 页面验收

- [ ] 上传保持源格式与字节一致，不额外生成 .docx.md/.xlsx.md；原格式文件按一份计数。
- [ ] 添加、覆盖、保存失败、重试和部分成功均有真实状态。
- [ ] 文本保存失败保留草稿；外部改动不被静默覆盖。
- [ ] 所选资料跨页后范围正确，无重复路径前缀。
- [ ] 知识页链接可用，缺失与歧义不乱跳。
- [ ] 默认只读与高级修订边界符合最终启用策略。
