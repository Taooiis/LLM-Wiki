## 一页速览

- **是什么**：Windows 桌面知识库维护工具（取代 LLM Wiki Demo 的 Node 服务 + 浏览器面板方案）。
- **壳与内核**：C# 宿主（先 .NET 10 LTS，.NET 11 GA 后升级到 11）+ WPF UI Library（WPF-UI 4.3.0）原生控件，全 WPF 化、放弃 WebView2；文件桥内置在 C# 里，不再依赖 Node。
- **定位**：只做知识库维护（建库 / 传文档 / 预览编辑 / 提示词生成）；不做问答、不内置 AI。
- **AI 链路**：与 demo 相同——客户端生成提示词 → 人复制到外部 Agent（opencode / codex 等）→ Agent 直接读写知识库文件。
- **源格式**：txt / md / docx / xlsx 四种；docx 与 xlsx 在上传时转成 Markdown 副本入库，原件保留在 `raw/original/`。
- **多设备（两层）**：电脑端把存储路径配成局域网共享（UNC，全程点选）即可访问同一知识库；手机 / 无客户端设备用应用内开关暴露的只读网页（4 位 PIN 门槛，只读）。
- **视觉**：Windows 11 Fluent 深色优先 + Light 主题，Windows 蓝强调色；禁止紫色。以《页面级设计》00-07 为准。
