## 新版结构

主流程：添加资料 → 整理知识 → 查看结果 → 确认处理。日常阅读默认进入知识。

- 主导航：知识、资料、整理。
- 低频入口：连接与分享、知识库设置、应用设置、使用帮助。
- 已验证本机工具可用时主按钮“开始整理”，否则“复制整理指令”；导出任务包为高级入口。
- MCP 是可组合的资料访问方式，不与启动器互斥。
- 七类提示词合并为三类任务，每次复制自动组合库上下文；无需先单独粘贴边界说明。
- 待整理清单集中维护；复制指令不等于执行完成。
- 资料保持源格式、不转 Markdown，保留目录约定和外部 AI 定位。

可整份阅读：[详细设计完整版](完整版.md)。

## 实施说明

先读 00、01、03、13、14，按 09 阶段 0 核实源码。纯布局和服务权限分开改，每次处理一个阶段。复用底层文件桥和模板引擎；上传链路取消 Markdown 转换，格式读取与预览按需适配。

纳入用户主动的本机 Agent 调用；不内置聊天/模型 API，不做无人值守自动执行、云同步、图谱、数据库或复杂调度。当前目录只有设计资料，开始开发需要实际项目，不据此宣称 V2 已完成。

本目录是唯一设计规范。历史设计与旧概念图已删除，必要数据和服务规则已整合到第 10、11 章。实施映射中的已有页面、存量库和旧客户端是程序兼容对象，不是需要另行阅读的设计文档。分章为维护源，完整版由 00—15 章生成；概念图只作视觉参考。
