1. 先读 [总体架构与实现约定](00_总体架构与实现约定.md)，确认实际代码与已有组件映射。
2. 每次选一个页面，阅读该页全部MD和同名PNG，按页内步骤实现控件/样式/命令/异常，不只还原静态布局。
3. 按 [实施步骤与验收清单](实施步骤与验收清单.md) 的阶段顺序交付；每页构建、深浅状态和真实交互检查通过后再继续。
4. 用户操作与应用内帮助以 [整体使用说明](使用说明.md) 为同一内容来源，实施后按真实版本校正。

## 技术与功能冻结

- 支持PDF、Word、表格/CSV、PPT、JSON等数据、文本和常见图片，具体扩展名见总体第3.1节；单文件20MiB，上传不转Markdown。存储、预览、编辑和AI读取分别验证。
- 知识/资料/整理三个主入口；首次无需单独粘贴边界，任务上下文自动携带。
- 已验证本机工具可直接开始；首个具体目标Codex CLI原生非交互适配，自动传任务，不要求用户再粘贴。
- 复制是兜底、导出为高级入口，MCP是可组合访问方式；本机进程结束不自动确认资料。
- 逐项核对一次提交，部分任务可结束保留剩余，同版本刷新/重启不回流。
- 源资料移入回收站可恢复，同名覆盖保留旧版本；永久删库另行确认。
- 页面深浅主题的选中/失焦/焦点必须完整，不能用默认控件黑字白块代替图示。

7张页面图使用同一知识页壳和深色Fluent视觉语言，1张公共反馈图补充深浅主题弹框与通知，逐张检查并纠正与规格冲突的生成文案。图片均为设计基准，不是程序已实现截图，也不是可自动导入的XAML。路径/版本/日期/日志是示例，不能硬编码。

数值和状态以MD为准，风格与主几何按图；没有写出的能力不因图上一个图标自动新增。既要做截图覆盖对比，也要验证真实命令与服务；仅有图和文档无法保证未经实测的程序逐像素相同。
