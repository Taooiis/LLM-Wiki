# 06｜配置、设置与小白指南

## 1. 页面关系

底部导航包含三个入口：配置、设置、小白指南。三者职责分开：

- 配置：知识库运行所需的路径、purpose、schema 等业务配置。
- 设置：应用自身偏好，如主题、版本信息、更新检查。
- 小白指南：静态帮助内容，指导新用户完成日常任务。

### Light 主题适配

- 卡片：Dark `#2B2B2B` / Light `#FFFFFF`
- 边框：Dark `#454545` / Light `#D6D6D6`
- 文字：Dark 主 `#F5F5F5`、次 `#C5C5C5`、三 `#9A9A9A`；Light 主 `#1A1A1A`、次 `#5C5C5C`、三 `#8A8A8A`
- 状态徽标：Dark 绿 `#6CCB5F`、黄 `#FCE100`、红 `#FF6B6B`；Light 绿 `#0F7B0F`、黄 `#9A6700`、红 `#C42B1C`

## 3. 存储路径配置

- 路径输入框支持手动输入，输入变化立即触发格式/可访问性校验
- 浏览按钮调用 Windows 原生 Folder Picker
- 显示路径状态：`✓ 路径可用 · 目录存在` / `⚠ 路径不可用 · 无权限` / `⚠ 路径格式错误`
- 保存按钮仅在路径有效时启用
- 保存成功：写入配置文件、创建必要目录、更新全局路径服务、刷新知识库列表
- 路径切换期间需要明确处理正在编辑的文档、运行中的分享服务和工作流任务

### 实现细节（PathStatusText）

- 输入框空：状态「未填写路径」；取消按钮不可点
- 格式错误：状态「路径格式错误」；取消按钮不可点
- 解析后目录不存在（可创建）：状态「路径可用 · 目录不存在（保存后自动创建）」
- 目录存在：状态「路径可用 · 目录存在」
- 无权限：状态「无权限」；取消按钮不可点（弹出权限错误）

## 4. purpose.md / schema.md 编辑

- 两张卡片分别展示文件用途、当前状态（存在/缺失/保存中/已保存）
- 点击「创建默认模板」按钮时，先在编辑框中填入默认内容，再保存
- 保存失败：弹出错误 toast，状态「保存失败，内容已保留」；编辑框内容不被清空
- 两个入口应共用文件读写服务，避免一处保存覆盖另一处未保存内容
- 文件缺失时提供「创建默认模板」入口；创建前展示将写入的默认内容摘要

### Purpose 模板示例

```markdown
# 知识库目标

## 目标
（描述这个知识库要解决什么问题、服务谁）

## 关键问题
- 

## 范围与边界
- 包含：
- 不包含：
```

### Schema 模板示例

```markdown
# 结构规则

## 页面约定
- 每个 wiki 页面顶部使用 YAML frontmatter，含 sources: []
- 断言标注来源：[来源: 文件名]
- 页内互链使用 [[页面名]]

## 目录分类
- entities/：实体（人、产品、组织）
- concepts/：概念与方法
- sources/：源文档摘要
- queries/、synthesis/、comparisons/：问答、综合、对比
```

## 5. 设置页

内容保持简洁：

- 外观：Dark / Light 切换；默认 Dark。主题选择即时生效并记住（写入 config.json）
- 版本：应用真实版本号，`v{AssemblyVersion}`
- 更新：检查更新按钮，显示「正在检查…」、「已是最新版本」、「发现新版本 v{x.x.x}」或「检查失败：{reason}」
- 可选：仅在产品已有对应功能时出现

### 主题持久化实现

- `ThemeService.Apply(theme)`：替换 `Application.Current.Resources.MergedDictionaries` 中的 Theme.Dark.xaml / Theme.Light.xaml
- `ConfigService.SetTheme(theme)`：写入 config.json，`theme` 键值为 "Light"/"Dark"
- 启动时 `MainWindow` 调用 `AppThemeService.Apply(configService.Theme)` 快速还原
- Light 主题采用加深的状态色（绿 `#0F7B0F`、黄 `#9A6700`、红 `#C42B1C`），确保在浅色背景上可读

## 6. 小白指南

使用 5 个分组折叠面板：

1. 快速上手：创建知识库、选择当前库、认识页面布局
2. 日常使用：上传文档、新建 Markdown、编辑保存、删除文件
3. 知识维护：待处理变更、批量 Ingest、增量 Ingest、Lint、Compare、Clean
4. AI 协作：复制提示词、交给 Agent 执行、将结果放回知识库
5. 运行与网络：存储路径、局域网分享、PIN、安全边界

指南文字要短句、按步骤、使用与界面一致的按钮名称。

## 7. ViewModel 建议

### 配置页 ViewModel

- `WikisDir`、`WikisDirInput`、`IsPathValid`、`PathStatusText`、`PathErrorMessage`、`PathIsOk`
- `PurposeContent`、`PurposeExists`、`PurposeStatus`、`SavePurposeCommand`、`CreateDefaultPurposeCommand`
- `SchemaContent`、`SchemaExists`、`SchemaStatus`、`SaveSchemaCommand`、`CreateDefaultSchemaCommand`
- `ValidateWikisDirCommand`、`SaveWikisDirCommand`、`ResetWikisDirCommand`

### 设置页 ViewModel

- `AppVersion`、`CurrentTheme`、`UpdateStatus`、`IsCheckingUpdate`、`HasUpdate`
- `ChangeThemeCommand(parameter)`：parameter="light"/"dark"
- `CheckUpdateCommand`、`OpenDownloadPageCommand`

### 指南页 ViewModel

- 5 组 Expander：每组标题 + 是否展开状态；默认展开「快速上手」
