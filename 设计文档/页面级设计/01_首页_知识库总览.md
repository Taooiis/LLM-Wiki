# 01｜首页：知识库总览

## 1. 页面目标

首页是进入应用后的工作台。用户打开后应立即知道：当前有哪些知识库、当前库的资料规模、是否有待处理变更、存储位置是否正常，以及下一步可以做什么。首页不能只是四个数字，也不能把所有功能入口堆成一排按钮。

## 3. 页面分区与视觉细节

### 3.1 标题区

- 左侧标题“首页”，下方一行简短说明：`管理知识库、源文档和知识更新状态。`
- 右侧主按钮：`新建知识库`，蓝色实心按钮。
- 不再放置多个同级主按钮；上传、浏览等操作放入快捷入口。

### 3.2 欢迎 Banner

- 横向卡片，高度约 112–132px；底色使用 `#252B30` 或同色系微弱层次，不使用渐变色。
- 左侧标题：`欢迎使用 LLM Wiki`；说明：`把分散的资料整理为可持续维护的知识库。`
- 右侧可以放轻量线性知识图谱/文档图标组合，不要使用大面积装饰插画遮挡文字。
- 两个轻量按钮：`打开源文档`、`查看工作流`。
- 如果不需要 Banner 的视觉高度，可在窄窗口下压缩为普通说明行。

### 3.3 四张统计卡

四卡等宽，桌面宽屏一行显示；小窗口两列。

| 卡片 | 主值 | 辅助文案 | 点击行为 |
|---|---|---|---|
| 知识库 | 当前知识库总数 | 个知识库 | 跳转知识库列表/定位我的知识库 |
| 源文档 | 当前选中库的源文档数，需明确口径 | 份源文档 | 跳转源文档页 |
| 待处理变更 | 当前选中库待处理数 | 需要重新 Ingest | 跳转工作流或源文档变更区 |
| 存储状态 | 正常/异常/未配置 | 当前路径摘要 | 跳转配置页 |

- 数字 28–32px，标签 13px，辅助文字 11–12px。
- 图标使用低对比度蓝色/灰色底，不做彩色大圆形渐变。
- 待处理数大于 0 时可显示小型警示标识；为 0 显示“全部已同步”或“暂无待处理”。
- 存储状态不能仅根据路径字符串存在判断，应使用真实校验结果；无法验证时显示“未验证”。

## 4. 我的知识库区域

- 区块标题：`我的知识库`，右侧显示总数和排序方式（最近访问/名称）。
- 搜索框在标题下方，输入即时过滤，不弹窗。
- 卡片列表每项显示：知识库名称、源文档数、最近访问时间、路径摘要（可选）、当前选中标记。
- 当前知识库用蓝色细边框或左侧蓝色指示条标记，不能只靠文字颜色。
- 单击卡片：切换当前库并刷新依赖数据；若当前有未保存编辑，先执行未保存保护。
- 双击卡片或点击“打开”：进入源文档页并选中该库。
- 更多菜单：删除知识库。删除必须确认，明确展示库名和不可恢复风险。
- 空状态：显示“还没有知识库”，主操作“新建知识库”，辅助说明默认存储目录。

## 5. 待处理变更区域

- 仅展示最近若干条（建议 3–5 条），不在首页呈现完整复杂表格。
- 每行显示文件名、变更类型（新增/修改/删除）、时间；类型用小徽标。
- 点击行跳转源文档页并定位对应文件/变更。
- `查看全部`进入完整变更列表；`去处理`跳转工作流增量 Ingest。
- 无待处理变更时显示轻量空状态：“当前知识库已同步”。
- 不能只显示红色告警而不给下一步操作。

## 6. 快捷入口与存储信息

快捷入口建议 2×2 小按钮或图标入口：上传文档、浏览目录、生成 Ingest、运行 Lint。入口点击后应直接进入对应页面并聚焦目标区域，不要再弹一个“请选择操作”窗口。

存储位置卡片显示：
- 当前根目录完整路径（超长时省略中间段，悬停显示完整路径）。
- 存储状态：正常 / 路径不可访问 / 未配置 / 正在检查。
- `打开配置`跳转配置页存储路径区域。
- 可选“在资源管理器中打开”，仅在路径存在且系统调用成功时启用。

## 7. 新建知识库交互

推荐使用页面内联创建区或轻量 ContentDialog（二选一，优先内联）：

1. 点击“新建知识库”。
2. 出现名称输入区，提示允许字符：中文、英文、数字、下划线、中划线。
3. 输入时即时校验；非法名称显示输入框下方错误，不关闭区域。
4. 名称重复时按现有规格处理：提示已存在并自动选中对应库（如果当前业务实现如此），不得覆盖数据。
5. 创建成功后刷新列表、自动选中新库、更新状态栏路径，并提示创建结果。
6. 创建骨架应沿用现有业务服务：`purpose.md`、`schema.md`、`raw/sources|assets|original`、`wiki/entities|concepts|sources|queries|synthesis|comparisons`。

## 8. 首页 ViewModel 建议

- `KnowledgeBaseItems`
- `SelectedKnowledgeBase`
- `KnowledgeBaseCount`
- `SourceDocumentCount`
- `PendingChangeCount`
- `StorageHealthState`
- `StoragePathDisplay`
- `RecentChanges`
- `SearchKeyword`
- `SortMode`
- `IsLoading` / `LoadError`
- 命令：`CreateKnowledgeBaseCommand`、`SelectKnowledgeBaseCommand`、`DeleteKnowledgeBaseCommand`、`OpenSourceDocumentsCommand`、`OpenWorkflowCommand`、`OpenConfigurationCommand`。

统计卡值应来自同一数据服务或明确的统计服务，避免各卡各自扫描磁盘导致数字口径不一致。

## 9. 验收清单

- [ ] 首页在 1440×900 下与概念图布局接近：欢迎区、统计卡、知识库和右侧信息区层次清楚。
- [ ] 4 张统计卡在宽屏同一行，窄屏自动换行。
- [ ] 当前库有明显选中态；切换后其他页面数据同步刷新。
- [ ] 新建知识库成功自动选中，重名不会覆盖原数据。
- [ ] 待处理变更可定位到源文档或工作流。
- [ ] 存储异常显示真实错误，不伪装为正常。
- [ ] 空状态、加载态、异常态都有设计。
