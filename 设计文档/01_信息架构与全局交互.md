## 2. 知识库切换器

下拉面板包含搜索库名、现有库列表、当前库标记、“新建知识库”“管理当前知识库”。列表显示名称和路径摘要；不在此处扫描全盘统计。

- 单击库名切换，不要求双击。
- 切换先处理当前编辑，再取消旧页面加载，最后刷新依赖上下文的数据。
- 慢请求带知识库上下文版本，旧库请求晚返回不得覆盖新库页面。
- 当前库被外部删除：保留错误提示，要求选择其他库；不自动新建同名空库。
- 切换后的默认页为该库上次访问的“知识/资料/整理”；首次进入为知识。
- 对外服务绑定的库不随切换改变，顶部提示“浏览分享仍在分享：产品研究”，可跳转管理。

## 3. 创建知识库

一个轻量对话框内填写“知识库名称”，选择模板“通用/研究/读书/业务”，可展开“目标说明”。默认通用，不强迫先写配置。

名称即时校验，复用原服务的合法字符规则；重名显示“这个知识库已存在”，提供“打开已有知识库”，不覆盖。创建中防重复提交；成功选中新库进入资料空状态，主按钮“添加资料”。

无库启动时内容区显示三步：“创建知识库 → 添加资料 → 整理成知识”，只突出“创建知识库”。用户不必先配置路径。路径不可访问时显示修复入口，不能误显示为没有知识库。

## 4. 统一布局与视觉

保留 .NET 10、WPF、WPF-UI 4.3.0、MVVM 的既有基线，不在设计期重选技术栈。优先项目已封装业务控件，其次 WPF-UI，再用 WPF 原生控件。现有服务和控件名称以源码盘点结果为准。

| 项目 | 规范 |
|---|---|
| 窗口 | 建议 1440×900；1180×760 为推荐最小工作尺寸；1100×650 核心操作仍可通过滚动访问 |
| 导航 | 208—224px，可折叠为 64px；只持久化布局偏好 |
| 顶栏/状态栏 | 约 52px / 28px；长路径在详情而非状态栏完整铺开 |
| 页面留白 | 左右 24px，区块间距 16px；正文 14px，标题 26px |
| 主操作 | 每个任务区一个主要蓝色按钮；不可恢复删除采用危险样式，可恢复移除显示“移入回收站” |
| 颜色 | 延续原主题 Token；深浅主题齐全；Windows 蓝强调，禁止紫色渐变与发光 |
| 内容布局 | 文档列表/目录树 + 阅读编辑区；表单按需展开，避免所有功能卡同时堆叠 |

主题资源集中管理，状态同时有文字和图标，不能只用颜色。图标按钮有 Tooltip、AutomationProperties.Name 和可见焦点。

## 5. 全局查找与局部筛选

顶栏 placeholder 固定为“查找当前库文件…”，按文件名搜索资料和知识，结果分组显示名称与相对路径。Ctrl+K 聚焦，方向键选择，Enter 打开选中项，Esc 收起。跨页打开也执行未保存保护。

局部搜索分别标为“筛选资料文件名”“筛选知识目录”，只过滤当前页。MCP 的内容搜索不等同桌面的全局搜索，不能因服务有该工具就声称桌面已有全文检索。若后续接入真实正文搜索，提供明确的“文件名/正文”范围及加载、截断状态。

## 6. 保存与离开保护

触发：切文件、切页、切库、改根目录、关闭窗口、关闭正在编辑的面板。

统一按钮：“保存并继续 / 放弃更改 / 留在此处”。保存失败留在原页面，显示原因与重试；放弃只丢弃当前草稿，不撤销已经落盘的修改。任务表单未生成输入在会话内保留，正常离开有保护；生成后的任务快照跨重启保存。文档意外崩溃草稿本版不保证恢复，不与任务恢复混为一谈。

保存期间锁定目标文件标识，不能随选择变化把内容写入另一文件。写回前发现磁盘文件发生变化，显示“文件已被其他程序修改”，提供“查看磁盘版本 / 另存副本 / 返回编辑”；不提供无说明的覆盖。

## 7. 状态、消息与快捷键

| 类型 | 表达 |
|---|---|
| 加载 | 区域内进度，保留旧内容但标记正在刷新 |
| 真正空白 | 一句话解释 + 对应主操作 |
| 无搜索结果 | “没有匹配文件” + 清空筛选 |
| 加载失败 | 错误摘要 + 重试；不显示暂无数据 |
| 成功 | Snackbar“已保存”“已复制整理指令”等，约 3 秒 |
| 长期状态 | 页面内保留“等待外部执行”“分享中”等，不只使用 Toast |
| 详细错误 | 可展开技术详情，默认中文；不包含令牌、PIN 和文档正文 |

Ctrl+S 保存当前编辑文档；Ctrl+F 聚焦页内筛选；F5 刷新当前页并保护草稿；Esc 关闭轻面板，编辑中先执行保护；Ctrl+N 仅资料页且焦点不在文本控件时新建资料。

保存按钮、保存后是否退出编辑及人工修订保护统一见 [闭环补全规范第 7 节](11_闭环补全与状态恢复规范.md#7-文本编辑与手动知识修订)。

普通保存、复制、可恢复移入回收站与结果勾选后的确认不重复弹确认框；危险操作才单独确认。首次整理无需先单独粘贴库说明；已配置适配工具时主按钮“开始整理”，否则“复制整理指令”。普通确认减负见第 12 章，执行入口见第 13 章。

## 8. 通用组件复用清单

库切换器、文档工作区、文件元信息栏、未保存对话框、操作反馈、错误区、待整理清单、指令预览面板应复用已有封装。数据可共享服务，但不同页不共用会互相覆盖的编辑缓冲区；相同文件的冲突由统一文件版本校验处理。
