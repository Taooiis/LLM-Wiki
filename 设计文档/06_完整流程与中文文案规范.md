# 06｜完整流程与中文文案规范

## 1. 首次使用流程

```text
启动
 ├─ 根目录无法访问 → 修复存储路径 → 重试
 ├─ 没有知识库 → 创建知识库 → 资料页
 └─ 已有知识库 → 恢复当前库 → 上次主页面

资料页 → 添加文件 → 查看结果 → 整理新增资料
       → 复制完整任务指令 → 到外部 AI 执行 → 查看知识 → 确认处理
```

首用引导仅在无库或没有资料/知识时出现。已有库的老用户不强制完成向导、不重新创建配置、不自动执行整理。

首次和日常都在整理页操作，库说明与任务自动组合。已配置并验证本机工具时点击“开始整理”，否则“复制整理指令”到外部 AI 执行。只有选择 MCP 且尚未配置客户端时才去连接页；没有 MCP 也能走完整流程。

## 2. 日常新增和修改

1. 从资料页添加文件或编辑文本并保存。
2. 页头提示“有 2 项资料变更尚未整理”，提供“去整理”。
3. 整理页默认待整理范围，用户选择对应项。
4. 点击“复制整理指令”，上下文与本次任务一次复制，在外部执行。
5. 返回查看知识内容和来源，确认本次处理。
6. 剩余项继续保留；没有待整理项时显示“暂无待整理变更”，不用“全部知识已同步”，因为系统无法证明外部结果正确。

不要求每次修改都跑全部资料；不把未整理当成保存失败。资料保存成功与知识尚未更新可以同时成立。

## 3. 删除资料与清理知识

```text
移入回收站 → 原格式文件可恢复 → 记录删除变更
  → 整理中心选择删除项 → 生成引用清理计划
  → 外部核对受影响知识 → 在允许范围执行修订/本机确认删除
  → 检查知识链接和共享实体 → 确认该删除变更已处理
```

资料删除后知识仍存在是可解释状态，不自动清掉引用或整页知识。只读 MCP 无法写；写 MCP 也不支持文件删除。执行说明必须针对连接能力生成，不让用户等待永远无法完成的操作。

## 4. 阅读与分析

打开知识页 → 浏览目录/文件名查找 → 阅读正文 → 点击来源回到资料。想提问时进入整理/提问分析，填写问题并选择外部执行方式。阅读工具与问答指令相互衔接，但不将知识页伪装为内置聊天。

## 5. 共享与切库

启动浏览分享前明确库名 → 获取地址与 PIN → 其他设备输入 PIN 浏览 → 桌面切到另一个库 → 状态栏仍明确原库在分享 → 用户在连接页停止或更换范围。

切换根目录前先解决草稿和服务；取消任一步时不继续。退出桌面时停止桌面宿主服务；独立 stdio 的停止方式另作说明。

## 6. 异常恢复流程

| 异常 | 保留内容 | 恢复入口 |
|---|---|---|
| 文件上传部分失败 | 已成功项、失败清单 | 重试失败文件 |
| 文件保存失败 | 原有效文件；未完成临时文件不算入库 | 查看原因、重新上传 |
| 原格式内容读取失败 | 原文件与待整理状态 | 更换读取工具或稍后重试，不自动转 Markdown |
| 编辑保存失败 | 当前草稿、原文、目标路径 | 重试保存/另存副本 |
| 外部 Agent 改了当前文件 | 用户草稿、磁盘新版本 | 查看冲突/另存副本 |
| 共享目录断开 | 当前上下文和草稿 | 重连后重试；不用空列表冒充无数据 |
| 外部 AI 未执行或中断 | 待整理变更 | 重新复制指令；应用不猜测完成率 |
| 生成后又有变更 | 新变更记录 | 重新生成或仅确认未变化项 |
| 分享启动失败 | 用户配置，不保留假运行状态 | 修改端口/查看网络后重试 |
| 设置持久化失败 | 原生效配置、当前输入 | 重试，不显示已应用 |
| 文件已保存但记录失败 | 源文件、持久修复凭据 | 重试登记，不重复上传 |
| 应用重启后继续整理 | 原任务范围、版本和确认进度 | 打开未完成任务；本机 attempt 中断先核实进程，不推断执行成功 |

## 7. 中文术语表

| 技术/旧名 | 面向用户的中文 | 使用规则 |
|---|---|---|
| Source、源文档 | 资料 | 导航与主要按钮统一用资料 |
| Wiki 目录浏览 | 知识 | 路径说明仍可写 wiki/ |
| Pending changes | 待整理变更 | 导航徽标简称待整理，不写待同步 |
| Ingest | 更新知识 / 整理资料 | 高级详情可附 Ingest，主按钮不出现 |
| Batch / Incremental | 全部资料 / 待整理变更 | 用范围表达，避免两个工作流 |
| Boundary | 库说明 | 自动随任务携带，高级入口可单独查看 |
| Query / Compare | 回答问题 / 对比主题 | 不命名为发送消息 |
| Lint | 检查知识质量 | 生成后不说检查完成 |
| Clean | 处理已删除资料的引用 | 首先生成计划，避免像直接删库 |
| Prompt | 操作指令 | 预览详情可说明“发给外部 AI 的提示词” |
| MCP | MCP 连接 | 首处解释“供外部 AI 工具读取知识库的协议” |
| PIN | 访问码 | 浏览分享专用，和 MCP 令牌分开 |
| purpose/schema | 目标与边界 / 组织规则 | 中文标题旁附真实文件名 |

## 8. 可直接使用的界面文案

| 场景 | 文案 |
|---|---|
| 无知识库 | 创建你的第一个知识库，把资料和整理结果放在同一个地方。 |
| 有资料无知识 | 资料已准备好。整理成知识后，就能在这里阅读。 |
| 待整理提示 | 有 {n} 项资料变更尚未整理。 |
| 保存成功 | 资料已保存，知识内容尚未更新。 |
| 复制成功 | 已复制整理指令。请到外部 AI 工具中粘贴执行。 |
| 确认前 | 将从待整理清单中移除所选 {n} 项。请先确认它们已在外部完成处理。 |
| 确认有新变化 | 已确认 {a} 项；{b} 项有新变化，仍保留在待整理清单中。 |
| 无待整理 | 暂无待整理变更。你仍可以选择资料重新整理。 |
| 只读连接 | 此连接只能读取内容，不能写回知识。 |
| 外部执行未知 | 本应用无法确认外部 AI 是否完成，请查看结果后再确认处理。 |
| 保存冲突 | 文件已被其他程序修改。你的编辑内容已保留。 |
| 路径切换 | 只更换读取位置，不搬迁或删除原目录文件。 |
| 分享中切库 | 浏览分享仍在分享“{kb}”。切换当前知识库不会更换分享范围。 |
| 只读浏览页 | 只读浏览 · 编辑请回到桌面应用。 |
| 资料删除 | 已移入回收站，可恢复；已有知识不会立即删除。 |
| 记录待修复 | 文件已保存，变更记录未完成。请重试登记，无需重新上传。 |
| 规则更新 | 规则已更新，已有知识尚未按新规则核对。 |
| 任务恢复 | 有未完成任务，可继续核对。 |
| 结果范围 | 以下是任务准备以来的文件变化，可能包含其他程序的修改。 |

按钮写动作和对象，如“添加文件”“保存目标”“停止浏览分享”，避免“确定”“提交”“运行”作为不明确的全局文案。错误先说明发生什么，再给下一步，不把堆栈放在主提示中。
