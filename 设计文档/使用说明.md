# LLM Wiki｜整体使用与配置说明

> 对应本目录页面整合设计。应用改造后按真实按钮与运行结果发布本说明；当前文档不是程序已经实现的证明。

## 1. 工具如何使用

资料是输入，知识是整理结果，整理页负责把两者连起来。你的文件保存在本地或你配置的共享目录，AI任务在外部工具运行；应用不内置聊天、模型账号或API Key。

日常流程：**添加资料 → 选择整理范围 → 本机开始或复制执行 → 检查结果 → 确认已完成项**。阅读时直接进入知识页，不必每次整理。

| 页面 | 用途 |
|---|---|
| 知识 | 阅读结果、浏览分类、查看来源 |
| 资料 | 添加/新建/修改原始内容、回收恢复 |
| 整理 | 更新知识、提问分析、检查维护、结果确认 |
| 连接与分享 | 配置本机Agent、MCP和只读浏览分享 |
| 知识库设置 | 当前库的目标、组织规则、路径信息、危险删库 |
| 应用设置 | 所有库的根目录、外观、版本 |
| 使用帮助 | 按任务找步骤并返回原任务 |

## 2. 首次建立知识库

1. 双击实际安装的应用程序。无知识库时点创建；已有库时从顶栏库切换器创建或选择。
2. 输入库名，选择通用/研究/读书/业务模板，不确定就用通用。模板只预填规则，不改变文件结构。
3. 创建成功进入资料页，点添加文件，选择PDF、Word、表格、PPT、JSON等资料，或文本/图片；系统选择器按类型分组。
4. 查看分项结果；成功项可继续整理，失败项单独重试。

默认数据位置是系统文档目录下LLM Wiki/wikis，实际完整路径在应用设置可查。安装位置与数据位置独立。目录不可达时先修路径，不要把访问失败当作没有库而新建同名。

文件上传保持源格式和原始字节，不生成Markdown副本；单文件最大20MiB，多文件分别处理。可上传不代表可在应用中编辑，也不代表当前AI工具已能读取全部内容。

| 资料 | 支持添加的常见格式 | 如何使用 |
|---|---|---|
| Word/兼容文档 | docx、docm、doc、rtf、odt、wps | 内容预览或打开原文件，原格式交系统程序编辑 |
| 表格 | xlsx、xlsm、xls、csv、tsv、ods、et | 按工作表/行列预览；CSV/TSV可查看和编辑原文 |
| 演示文稿 | pptx、pptm、ppt、odp、dps | 按幻灯片内容/备注预览，完整演示打开原文件 |
| PDF | pdf | 按页文字预览；扫描内容需要具备视觉/OCR能力的工具 |
| 文本 | md、markdown、txt、log | 阅读及小文件原位编辑 |
| 数据 | json、jsonl、xml、yaml、yml、toml、ini | 保持原文，不自动格式化或改内容 |
| 图片 | png、jpg、jpeg、webp、bmp、gif、tif、tiff、svg | 可解码则预览，否则打开原件；AI视觉能力单独判断 |

旧版/兼容格式如果没有读取器，会显示已入库与需外部打开，不要求转MD。加密、损坏、超大、需要OCR等原因会分别提示。宏、嵌入脚本不会在应用预览中执行。压缩包、程序、音视频等不在当前支持列表。

## 3. 最简单的第一次整理：复制方式

1. 资料页勾选文件，点整理所选；也可打开整理页，选全部资料或待整理变更。
2. 执行入口选复制，点“复制整理指令”。完整指令自动包含库路径、规则入口、操作边界和本次任务，首次也不用先单独粘贴边界说明。
3. 到能够访问该文件夹的外部AI工具粘贴执行。普通网页聊天若无法访问本机文件夹，不会因为有路径文字就获得访问能力。
4. 返回该任务，点“我已在外部执行，核对结果”。不用等待本机完成事件。
5. 查看本次知识变化，打开正文核对来源；勾选确实已完成的资料，点“确认完成这n项”。不再重复弹普通确认框。

复制只是进入剪贴板，不代表AI已运行；文件变化也不代表内容正确。知识没变化但你已核对无需更新，可选择无需修改并填理由。没有外部结构化报告也能人工核对，不必制造一个文件修改才能结束。

## 4. 本机自动传任务：首次配置

1. 打开连接与分享→AI工具→本机执行工具。
2. 选择已实现的适配器；首个目标为Codex CLI原生非交互适配。选择并显示真实原生CLI程序路径，不是随便选一个AI桌面应用。
3. 点检测安装与登录；缺程序先安装兼容CLI，未登录到外部工具完成登录，返回重新检测。应用不收账号密码或模型Key。
4. 点验证实际执行。这会通过外部工具已有账号真实调用小测试，可能使用该工具额度；安装/有凭据不等于实际运行已通过。
5. 查看能力：TXT/MD通过不等于Word/Excel/PDF/PPT或图片可读，展开检测卡查看具体后缀、读取途径和限制，按需验证所选格式。选择访问方式和只读/当前库写配置，核对权限后保存并使用。

文件访问允许外部工具按操作系统权限读写，不是MCP仅wiki范围的强制隔离。只读可分析检查；需要写知识时要合适的写配置，不静默提升。

## 5. 本机执行的日常流程

工具Ready且本次格式/权限匹配时，整理页显示开始整理；分析/检查显示对应动词。点击后应用自动启动外部CLI、传入完整指令、接收真实输出，无需去粘贴。

所选资料有未验证或不可读取的格式时，按提示验证、换工具/访问方式，或明确只处理可读子集；没选入本次的资料继续待整理，不会偷偷跳过后报全部完成。表格不止第一张表、PPT不止第一页；结果中检查实际读取范围和遗漏。扫描PDF/图片需要视觉或OCR能力，空提取结果不能当无需更新。

如果按钮之后仍要求粘贴，那是复制分支或本机适配尚未接通，回AI工具查看各项状态。不能把已保存程序路径或打开空终端当作执行成功。

运行时可切页/切库阅读，任务仍在原库；本机一次一个任务。取消可能留下部分修改，不自动回滚；长时间无输出只提示，不代表失败。关闭应用先处理草稿并取消核实任务，不默认后台脱离运行。

结束、异常或取消后都进入结果核对，零退出也不等于所有资料完成。意外重启显示中断待核实，先检查进程和磁盘，不盲目重跑整批；仅重试需要继续的当前版本项。

## 6. 部分完成、重启与任务结束

已准备任务会保存范围和版本，重启后可在未完成任务继续；上次已复制不会自动变已执行。未保存文档的崩溃草稿不保证恢复，Task恢复与编辑草稿是两回事。

只完成部分就只确认部分；失败/读取不完整/源后来变化的项继续待整理。用其他工具已完整处理时在行内填说明后一次提交。原任务全部变化或不想继续，可“结束本任务，剩余继续待整理”，任务归档但未处理源变化不清除。

确认成功后清单、导航数字、知识页提醒和任务状态一起更新；同一已确认版本刷新/重启不应回流。有新修改则重新待整理，这是保护新内容。显示“确认已保存，显示待刷新”时只重试显示，不重复执行清除。

## 7. 添加、编辑、覆盖与外部修改

资料页新建Markdown或纯文本，在右侧输入文件名和正文，首次保存才建文件。已有文本默认预览，编辑在同区域完成。无修改保存禁用，Ctrl+S保存成功继续编辑，完成编辑回预览。

保存失败保留草稿；磁盘同时被外部修改时先核对版本，不能静默覆盖。正常切文件/页/库/关窗会提示保存并继续、放弃或留在此处。

Word、表格、PPT和PDF保存原文件，支持则预览，否则用系统关联程序打开；在外部修改保存后返回刷新，应用检测原字节变化。内容预览未必还原全部排版/图表，遗漏会显示。无法预览不等于上传失败，AI是否能完整读取另看工具能力。

JSON等数据与CSV/TSV可在1MiB以内编辑原文；原编码不明时先选择编码，较大文件用外部程序编辑。语法有误会在正文附近提示，需保留现状时可点“仍按原文保存”；不会自动修复、重排键、改变数字或换行。应用里新建仍提供Markdown/纯文本，其他格式用现有文件添加。

同名上传先让你选覆盖/跳过/返回，覆盖前版本保留到回收站；不能安全保留则拒绝覆盖。成功与失败分项显示，不编造进度。

## 8. 误删恢复与永久删除

资料页“移入回收站”可以恢复；成功提示可撤销，更多→回收站可找历史条目。恢复原路径有同名文件时另存名称，不直接覆盖。已经执行过引用清理的源资料恢复后，知识仍需重新整理，不会自动恢复Wiki。

回收站不自动按时间清空，可导出需要保留的原文件，再手动永久删除/清空。回收站不是备份，磁盘损坏或整个库永久删除会一并丢失。

资料移除后生成知识不会立即删除；整理页选择删除变更，先生成引用清理计划，核对共享实体和链接后处理。MCP没有删除工具，真正文件删除可能需在本机确认。

整个知识库在知识库设置危险区永久删除，需输入库名，包含资料、知识、内部状态和回收站，不能当作从列表隐藏。运行任务或停服失败时不能删。

## 9. 阅读与手动修订知识

知识页左侧目录、右侧阅读，点击来源可回资料；无法可靠解析的引用只显示原名，不猜目标。搜索按文件名，不是全文或AI问答。

只读页只显示只读，不显示已保存。更多→手动修订才进入编辑；保存后记录人工版本保护，后续整理需核对保留人工内容。MCP覆盖保护文件会拒绝，你可在桌面核实后解除当前版本保护；拥有文件权限的外部程序仍可能改文件。

提问与对比到整理→提问分析；知识质量与清理到检查维护。答案/报告在外部AI产生，是否存入知识以任务和实际结果为准，不保证每次提问都存档。

## 10. 修改目标与规则

知识库设置→目标与结构：purpose定义服务对象、问题、范围；schema定义分类、来源和互链。默认模板可用，不必一开始重写。两文件草稿和保存状态独立，保存其一不清另一草稿。

修改后后续任务自动取最新规则，但已有知识不自动重写。规则提醒的稍后处理只是收起；按新规则全库核对后再显式确认。部分任务不会把全库提醒清掉，旧规则任务确认也不代表新规则完成。

## 11. 存储位置与外观

应用设置→存储，输入/浏览根目录，等校验后应用。恢复默认先填输入，应用后生效。切换只换读取位置，不搬迁/合并/删除旧目录；需要搬迁时停止访问、完整备份再手动复制整个库，别只拷wiki。

运行本机任务先结束/取消；草稿先处理；绑定网页/MCP先停，失败保留旧路径。独立stdio需在外部客户端停用/重启。共享目录断开不自动回本地或新建同名空库。

UNC路径需该设备真实可访问，Windows管理权限，避免多台同时维护同文件。主题深色/浅色即时生效并记住；实际版本/更新状态来自应用和已有渠道，不以图示版本为准。

## 12. 浏览分享与MCP

手机查看：连接与分享→浏览分享，确认库名、启动，设备同可信局域网访问真实地址并输入PIN。可浏览/下载，不能改资料。切当前库不会静默更换已分享范围，换范围需停并重新开启；用完停止。二维码默认不含PIN。

MCP可选：AI工具→MCP连接，启动授权库，按真实客户端配置。HTTP默认本机、只读；需要写知识由你显式授权与写令牌。重启恢复只读，不提供删文件/改资料规则或清变更工具。令牌与网页PIN不同，不放普通日志。

MCP负责受控访问，不会自己派任务；可由外部客户端发起，也可与已验证的本机适配组合。stdio由客户端启动，退出桌面不保证其结束。无可靠探测就不显示虚假连接成功。

## 13. 跨环境任务包

整理更多→导出任务包，默认说明与清单、不含资料；显式勾选才包含所选源文件和规则，保持原字节，不包含凭据、回收站、内部状态。接收方用自己的根目录执行。

导出不表示完成，结果不自动同步。本版不自动导入覆盖知识；回填后回原库核对，源若已变化不能按旧包盲目确认。

## 14. 故障与恢复速查

| 提示/现象 | 下一步 |
|---|---|
| 上传了知识没变 | 进入整理，发起外部任务，再核对确认 |
| 文件已保存，记录未完成 | 重试登记，不重复上传 |
| 确认后数字没刷新 | 如果提示已保存仅重试刷新；若重启同版本回流，属于需修复的应用问题 |
| Task一直挂起 | 主动核对、无变化填理由，或结束本任务保留剩余 |
| 本机配置不Ready | 分别查程序/登录/实际执行/格式能力，不只看已安装 |
| AI读不了PDF/Word/表格/PPT/图片 | 看具体后缀及OCR/视觉/读取范围，换有能力的工具；失败项不默认完成，不强制转MD |
| 手机进不去 | 检查运行/同网/LAN地址/PIN和主机网络规则，不关闭全部防火墙 |
| 路径切后看不到旧资料 | 检查根目录；切换不搬迁，别用新建同名库掩盖 |
| 存储断开 | 恢复连接，核实结果后补记，不推断所有文件已删除 |

备份应包含整个库的原格式资料、知识、规则与隐藏状态，在停写后进行；不通过普通文档备份密钥。误操作恢复、任务完成和权限问题无法靠直接清空`.changes.json`解决。

## 15. 认识弹框、通知与页内提醒

短通知只报告一次结果，例如文件已保存、指令已复制；不会自动代表知识已更新。通知上的关闭只收起提示，不取消已完成操作，也不清除未处理变更。带撤销的“移入回收站”提示停留较久，鼠标停在通知上会暂停计时；提示消失后仍可到回收站恢复。

持续留在页面上的提醒表示还有状态需要处理，例如文件已保存但记录未完成、任务待核对、规则已变化。按提醒中的重试登记、查看结果等入口处理；不要因为关掉提醒就认为问题已解决。

未保存框会列出文件，可保存并继续、放弃本次更改、留在此处。按Esc或关闭等于留在原处，不会丢输入。多文件一项保存失败时留在原流程，已成功保存的项不要求重复保存。

同名覆盖、永久清空、永久删库、提升权限和更换正在运行的服务范围会明确说明影响，一次确认即可。永久删库要求输入库名，名称为空/未匹配不能删除。恢复遇同名默认另存，不覆盖现有文件。

运行任务时退出应用会把未保存内容与任务合并在一个退出保护流程，保存或取消失败就留在应用；强制结束可能保留部分文件改动。普通主题切换、保存、复制、资料移入回收站、结果勾选确认不会再额外弹成功框。
